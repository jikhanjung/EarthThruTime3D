# 메인 globe의 맨틀 근사 중첩

상태: v0.12.0으로 2026-09-15 운영 배포 완료.
배포 검증은 [릴리스 기록](../devlog/20260915_jikhanjung_072_release_0120.md)을 참고한다.
계획은 [P05](../devlog/20260915_jikhanjung_P05_globe_mantle_approximate_overlay.md),
좌표계 근거는 [정합 검사](mantle-frame-alignment.md)를 따른다.

## 사용과 범위

PALEOMAP 계열 표면(PaleoAtlas 2016 또는 PaleoDEM)의 정보 패널에서 **맨틀 근사 중첩**을
켠다. 현재 시간 범위가 80·60·40·20·0 Ma를 모두 제공해야 한다. 2002년 지도와 최근 빙기
범위에는 제공하지 않는다. 켜면 재생을 멈추고 80 Ma·구면 투영으로 이동한다.

전 지구 Slabs(파랑), Piles(주황), 핵 경계 참고 구(회색)를 각각 토글할 수 있다.
맨틀은 절개 영역 밖에서도 유지된다. 절개는 지표만 가리며, 중심 경도·위도와 각반경을
조절할 수 있다(기본 80°E, 10°N, 45°). 위치 변경 후 보기 버튼으로 카메라를 맞춘다.
지표 불투명도 0–100%를 조절해 온전한 지표와 내부 구조를 비교한다.
회색 구의 반지름은 지구 반지름의 0.546배(약 3,479 km)인 표시용 상수다.
핵 온도·유동 계산이나 내핵/외핵 구분은 제공하지 않는다. 맨틀의 색 역시 온도·유속이 아니다.

연대 선택 및 메인 타임라인은 다섯 원본 시점으로 이동한다. 중간 연대는 가장 가까운
원본으로 맞추며 동률은 오래된 시점을 택한다. 이전/다음 버튼도 원본 시점으로 이동한다.
중첩 중 자동 재생은 멈추며, 80–0 Ma 밖이나 평면 투영 선택은 모드를 해제한다.
중첩 토글로 종료하면 진입 전 시간·카메라·투영 등을 복원하며 재생은 재개하지 않는다.
모바일 로딩 완료 후 패널을 접고, 근사 중첩 상태는 화면 캡션에 남긴다.

## 고정 A–A′ 단면과 공유 시간

분홍 선은 원본 OPT1의 85°E, 40°S–60°N 단면을 해당 연대의 변환으로 옮긴 것이다.
선을 선택하거나 단면 열기 버튼을 누르면 같은 연대의 팝업이 열린다. 절개 위치를
옮겨도 이 과학 자료의 단면은 이동하지 않는다. 메인 화면과 연결한 팝업은 서로 시간을
맞추고, 자료 로딩 중에는 이전 단면을 숨긴다. 오류 상태에서 새 연대처럼 표시하지 않는다.

팝업의 지역 지형은 별도 기준틀의 비교 자료이므로 연결 모드에서는 지역 지형 위의
85°E 선을 숨긴다. 메인 분홍 선은 OPT1 단면의 위치를 가리킨다. 지각 시나리오의 융기를
PaleoDEM에 더하지 않는다. 기존 독립 `/collision/`의 시간 조절과 재생은 유지한다.

## 근사와 좌표

각 시점의 [정합 결과](validation/mantle-frame-alignment.json)에 있는 아프리카 기준
`opt1_to_paleomap_matrix`를 적용한다: `p_globe = B C p_OPT1`.
B는 화면 축 변환이며 C는 전 지구 강체 회전이다. 원본 반경·깊이를 보존하고 지표 고도
과장을 맨틀에 적용하지 않는다. 인도 경계점 P95 차이는 시점마다 화면에 표시한다.
약 3–4° 차이를 허용한 탐색이며 엄격한 0.1° 정합 검사 통과나 히말라야–섭입판의 정확한
연결을 뜻하지 않는다. 기존 검사 결과의 승인 상태도 변경하지 않았다.

지표의 기후·빙하와 격자·경계선·지명에 같은 절개를 적용한다. 투명 지표에서는 선과
지명 불투명도도 함께 낮춘다. 지형 위 해안선은 정규화한 구면 위치에 지형 높이와
메시 해상도에 따른 작은 표시 여유만 더한다. 기존의 0.007 지구 반경 오프셋은 제거했다. 긴 해안선·판 경계 선분은 구면에서
0.1° 이하의 표시용 선분으로 나눠 현의 처짐을 줄인다. 원본 끝점과 대권 경로를
유지하며 원자료의 공간 해상도나 정확도를 높인다는 뜻은 아니다.
확대 시 고도 과장이 0이어도 상세 구면 메시를 사용해 해안선이 떠 보이는 현상을 줄인다.

## 설정·전송·복구

`annotations/mantle-overlay.json`이 다섯 회전 행렬과 원본·레이어 SHA-256을 고정한다.
서버는 원본 및 다섯 시점의 Slabs/Piles 해시가 모두 일치할 때만 설정을 제공한다.
기본 화면은 맨틀 요청 0건, 선택한 시점만 두 메시를 요청하며 핵은 브라우저에서 만든다.
새 원본 다운로드는 없다. 기존 해시 기반 API와 HTTP 캐시를 재사용한다.

180 ms 요청 지연으로 빠르게 지나간 연대의 요청을 줄인다. Younger/Older와 연대 선택으로
전환하는 동안 현재 지표·맨틀·절개·반투명도와 표시 연대를 유지한다. 다음 시점의 지표,
선 자료와 맨틀 메시를 함께 준비한 뒤 같은 렌더 프레임에서 교체하고 이전 GPU 자원을 해제한다.
로딩 안내에는 요청한 시점을 표시한다. 별도 다섯 시점 CPU 캐시는 두지 않는다.
취소된 응답은 이후 상태를 덮어쓰지 않는다. 바이트 길이·유한 좌표·인덱스 범위를 검사한다.
실패 시 절개와 투명도를 복구하고 재시도를 제공한다. 지표 자체가 실패하면
이전 지형을 새 연대처럼 보여 주지 않고 자료 없는 참고 구와 오류 안내를 표시한다.
같은 원본 시점으로 돌아오는 중간 연대 입력은 메시 요청 없이 시간 선택만 되돌린다.
연결 팝업에서도 실패 후 재시도하거나 다른 원본 연대를 고를 수 있다. 해제·투영 변경·WebGL context
상실은 진행 중 요청을 취소한다. 메시 보간·1만 년 tick·대류 솔버는 후속 과제다.

경로를 확인한다. 브라우저는 다섯 시점, 절개·투명도·핵 토글, 팝업 연동, 실패/재시도,
빠른 연대 변경, 취소, 투영 복원, 모바일·영문과 기존 지구본 동작을 검증한다.
