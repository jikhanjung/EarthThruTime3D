# 맨틀–판 모델 좌표계 정합 검사

2026-09-15 · v0.11.0 기반 · `feature/mantle-frame-alignment`

OPT1과 현재 Müller v1.2.4 판 모델은 검증한 다섯 연대·8개 판에서 **연대별 전 지구
회전으로 정합된다**. PALEOMAP은 같은 방법으로 정합되지 않는다. 따라서 메인 globe의
첫 내부 모드는 OPT1과 호환되는 판 레이어를 기반으로 구성하고, PALEOMAP 지표는
별도 비교 대상으로 유지하는 것이 이 검사의 결론이다. 운영 화면에는 아직 적용하지 않았다.

이는 [P04](../devlog/20260915_jikhanjung_P04_globe_mantle_section_integration.md)의
좌표계 선행 검사다. 전체 판 경계·고도 래스터·모든 연대의 검증을 완료했다는 뜻은 아니다.

후속 결정: 사용자가 대규모 탐색 목적에서 남은 위치 차이를 허용하여
[P05](../devlog/20260915_jikhanjung_P05_globe_mantle_approximate_overlay.md)의 **근사 중첩**을
진행했다. 아래 엄격한 정합 검사 결과는 바뀌지 않으며, 제품의 허용 기준과 구분한다.

## 자료와 재현

기존에 받은 세 아카이브를 사용한다. 추가 대용량 다운로드는 없다.

- [OPT1 시각화 자료 v3.0](https://zenodo.org/records/6622194): Cratons VTU의
  80·60·40·20·0 Ma 표면 경계점. 맨틀과 함께 배포된 복원 기하다.
- [Müller 판 모델 v1.2.4](https://zenodo.org/records/13636799):
  `optimisation/1000_0_rotfile_MantleOpt.rot`, `Cratons/shapes_cratons_Merdith_etal.gpml`.
  포함 README는 v1.1에서 맨틀 기준틀을 재최적화했다고 명시한다. 같은 논문 계열이어도
  OPT1과 동일한 절대 회전일 것이라고 가정할 수 없다.
- [PALEOMAP 2016](https://zenodo.org/records/10251792): `PALEOMAP_PlateModel.rot`.
  이 검사는 판 회전을 비교한다. PaleoDEM의 실제 래스터를 정합한 검사가 아니다.

세 자료는 CC BY 4.0이며 출처·해시는 기존 source manifest 및
[수치 기록](validation/mantle-frame-alignment.json)에 남긴다. OPT1의 성격과 기준틀의
배경은 [원 논문](https://se.copernicus.org/articles/13/1127/2022/)을 따른다.
아래 측정값과 변환 행렬은 프로젝트에서 산출한 진단값이며 저자가 제공한 변환표가 아니다.

```bash
.venv/bin/python scripts/audit_frame_alignment.py \
  --record docs/validation/mantle-frame-alignment.json
.venv/bin/python tests/frame_alignment_check.py
```

기존 `requirements-processing.txt`의 NumPy·SciPy를 사용한다. 실행 시 source manifest의
아카이브 크기·SHA-256과 회전 파일의 크기·해시를 검증한다. Cratons GPML과 각 VTU의
해시도 결과에 기록한다. 기본 출력은 Git에서 제외된 `data/derived/frame-alignment/`의
`report.json`, `preview.html`이다. HTML은 외부 라이브러리나 서버 없이 열 수 있고,
연대·비교 모델·아프리카 기준 보정·지역 확대를 선택한다. `--record`는 미리보기 점 배열을
뺀 검토용 수치 스냅샷을 저장한다. 파생 진단 기하에는 원본의 CC BY 4.0 조건을 유지한다.

## 화면 축과 깊이: 이미 일치하는 부분

원본 지리 좌표는 `p = (cosφ cosλ, cosφ sinλ, sinφ) × (1 − d/6371)`이다.
λ는 동경 양수, φ는 북위 양수, d는 km 깊이다. 메인 globe의 `onSphere`가 사용하는
로컬 좌표는 다음과 같다.

```text
B = [ 1  0  0 ]
    [ 0  0  1 ]
    [ 0 -1  0 ]
p_globe = B p = (x, z, −y)
```

이는 현재 mantle.js의 x축 −90° 회전과 같다. 따라서 화면 축에 별도의 임의 경도
보정은 필요 없다. 메인 `earth` 그룹의 카메라용 회전은 이 로컬 좌표 변환 뒤에 적용한다.
`B`는 오른손 좌표계와 반지름을 보존한다. 지리학적 기준틀 변환 `C(t)`까지 필요한 경우
`p_globe = B C(t) p_OPT1` 순서이며, `B`와 `C`를 뒤바꾸면 다른 결과가 된다.

단면도 같이 바꿔야 한다. 원본 85°E 단면의 법선 `n`과 선택 반평면 방향 `h`를
`C n`, `C h`로 옮기면 기존 단면의 물리적 위치를 유지한다. 반대로 목표 기준틀에서
새로 정의한 85°E 단면을 원본에서 자르려면 `Cᵀ n_target`, `Cᵀ h_target`을 쓴다.
단면 경로의 각거리·깊이는 회전으로 바뀌지 않는다. 수직 배율은 이 계산 이후의 표시다.

## 대응점과 검증 절차

1. Müller Cratons GPML의 현재 경계점을 OPT1 0 Ma 정점에 0.001° 이내로 대응시킨다.
   선택한 판 사이에서 소유가 겹치는 점은 제외한다. 최종 대응은 15,149점이다.
2. 대상은 Africa 701, India 501, India internal block 5011, Baltica 302, Siberia 401,
   Australia 801, North America 101, South America 201이다. PALEOMAP에는 같은 번호를
   비교용으로 사용하되 5011은 501에 대응시킨다. 이는 안정 대륙 내부의 비교 가정이며,
   판 경계 전체나 서로 다른 모델의 변형 블록이 같다는 선언이 아니다.
3. VTU는 정점 수가 같아도 연결 배열이 달라지고, 중복된 현재 점의 정점 번호가 과거에
   잘못된 대응을 만들 수 있다. 정점 번호만 신뢰하지 않는다. 짝수 순번 점으로
   원점 고정·배율 1·반사 금지 회전을 추정하고, 결정론적 합의 추정에서 과반의
   번호 대응이 지지하는 회전을 후보로 삼는다. 판 모델의 회전은 후보 추정에 쓰지 않는다.
4. 추정에 쓰지 않은 홀수 순번 점을 회전한 뒤 해당 연대의 실제 VTU 점과 공간적으로
   다시 대응시킨다. 모든 홀수 점, 그리고 전체 선택 점이 각각 0.01° 이내여야 한다.
   일부 점을 버리고 좋은 점의 평균만 보고 통과시키지 않는다. 후보를 찾지 못하거나
   전체 형상이 맞지 않으면 실행을 실패시킨다. 번호 재대응 개수와 검증점 수도 기록한다.
5. 이렇게 얻은 판별 원본 회전을 `R_OPT1,p(t)`라 하면 아프리카 기준 변환은
   `C(t) = R_target,701(t) R_OPT1,701(t)ᵀ`다. 다른 7개 판에서
   `R_target,p(t) [C(t) R_OPT1,p(t)]ᵀ`의 회전각 및 대응점 위치 잔차를 검사한다.
   아프리카 자체가 맞는 것은 정의상 당연하므로 다른 판의 결과가 핵심이다.

0.001°는 정점 식별 기준, 0.01°는 기하 대응 검사 기준이다. 기준틀 정합의 화면 검사에는
판 자세 잔차 0.1°를 사용했다(지표 각거리로 약 11.1 km에 해당). 이는 수치적 정합을
엄격하게 확인하기 위한 프로젝트 기준이며 지질학적 신뢰구간이나 원본 정확도가 아니다.
회전 자세의 각도와 특정 경계점의 위치 오차는 다르므로 두 값을 따로 보고한다.

독립 검증점의 강체 궤적 적합 최대 오차는 약 0.00000127°였다. 이 수치는 원본 자료의
과학적 정확도가 아니라 동일 기하를 재현한 수치 오차다. Müller에서 남는 공통 회전은
업데이트된 절대 기준틀의 차이라는 해석과 부합한다. 기존 README의 재최적화 설명과도
일치하지만, 이 검사만으로 모든 해양 판의 상대 운동까지 동일하다고 결론 내리지 않는다.

PALEOMAP에서는 아프리카를 맞춘 뒤에도 India 501 경계점 위치 P95가 각각
3.066°, 3.918°, 3.753°, 3.597°(80·60·40·20 Ma)다. 같은 시점의 다른 판에도 서로 다른
잔차가 남는다. 이는 전 지구 공통 회전만으로 제거할 수 없는 모델 간 상대 배치 차이다.
PALEOMAP에 맞추려고 맨틀을 판별로 따로 회전시키면 내부 연속 기하가 깨지므로 채택하지 않는다.

## 적용 범위와 다음 구현

- 다섯 연대의 `opt1_to_muller_matrix`는 **검증된 판 내부의 기하 비교를 위한 후보 변환**이다.
  행렬은 행 우선 저장, 열벡터 왼쪽 곱이다. NumPy의 점 배열에는 `points @ C.T`로 적용한다.
- 원본 맨틀을 유지하고 Müller 표면을 `C.T`로 옮겨도 같은 비교가 된다. 다음 통합은
  원본 맨틀·단면을 유지하는 OPT1 기준 장면을 우선 검토한다.
- 전체 동적 판 경계는 현재 최신 모델에 변경 사항이 있어 별도 검증이 필요하다.
  우선 OPT1에 동봉된 경계를 사용하면 이 변경을 혼합하지 않을 수 있다.
- 같은 다섯 시점만 검증했다. 저장된 회전 사이를 보간하거나 80 Ma 이전으로 외삽하는
  것은 승인하지 않는다. 필요한 시점을 추가 측정한 뒤 범위를 넓힌다.
- 기록의 `runtime_alignment_approved=false`는 자동 운영 적용을 막는 상태 표시다.
  이번 결과만으로 PaleoDEM·해안선·변형 지각·온도 또는 속도장을 정합 처리하지 않는다.
- P04의 구면 내부 레이어 구현에는 이 변환·단면 수학과 검사 기준을 사용하되,
  PALEOMAP 3D 지표는 현행 비교 패널을 유지한다. 이번 브랜치에서는 화면 통합·배포를 하지 않았다.

검증: 합성 좌표·깊이·회전 역변환·독립 SciPy 회전 비교·단면 반평면·정점 재대응과
실제 변형 거부 테스트 5개, 실제 세 아카이브 전처리, 비교 HTML 브라우저 조작을 확인했다.
Django 61개 테스트, `make check`, 기존 JavaScript 회전·투영 검사도 통과했다.
