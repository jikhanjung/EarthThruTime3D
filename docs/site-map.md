## 주소 매개변수 (`/`)

| 매개변수 | 값 | 뜻 |
|---|---|---|
| `masks` | `paleoatlas2016`(기본) · `paleodem2018` · `scotese2002` | 표시 자료 |
| `window` | `deglacial` · `lastcycle` | 시간 범위(고도 격자만): 최근 2.5만 년 / 13만 년, 1 ka 간격 |
| `age` | Ma 숫자 | 처음 보여 줄 시점 |
| `pin` | `경도,위도;경도,위도;…` (최대 3) | 위치 핀. 있으면 핀 스위치가 켜진다 |
| `steps` · `interval` | 허용 목록의 값 | 지도 사이 눈금 수 / 몇 Myr마다(전체 시대만) |
| `view` | `globe`(기본) · `mollweide` · `equalearth` · `equirect` | 투영 |
| `surface` | `relief` · `map` · `mask` · `temp` · `veg` · `rain` | 표면: 고도 · 원본 지도 · 대륙 마스크 · 기온 · 모형 식생 · 모형 강수 |
| `shading` | `0` · `1`(기본) · `5` · `20` | 지형 음영 |
| `sea` | m 숫자 | 해수면 조절. 시간 범위에서는 나이가 해수면을 정하므로 적히지 않는다 |
| `relief` · `rivers` · `ice` · `grid` | `0` · `1`(기본). 다른 값은 무시한다 | 입체 지형 · 잠재 하천 · 빙하 · 격자 |

예: `/?masks=paleodem2018&window=lastcycle`, `/?masks=paleodem2018&age=200&pin=126.98,37.57;-87.63,41.88`.

보기를 바꾸면 주소가 따라 바뀐다(마지막 조작 0.4초 뒤, 기본값과 다른 것만). 그 주소를 열면 같은 보기가
된다. `age`는 주소로 연 시점에서 벗어나면 적히고, 주소에 `age`를 담아 연 경우에는 계속 남는다. 예: `/?masks=paleodem2018&age=300&view=equalearth&surface=rain&shading=5`.

## 지구본 화면 (`/`) 구성

### 지구본과 조작
- 드래그 회전, 오른쪽 드래그 이동, 휠 클릭 또는 Shift+드래그 기울이기, 휠·핀치 확대.
  키보드 포커스 시 방향키 회전, `+`/`-` 확대.
- 캡션(왼쪽 위): 시대 / 나이 / 표면 종류 / 보간·가정·모델 복원 표시.
- 툴바: **☰ 설정** · **표시 자료** 선택 · **투영**(지구본·몰바이데·이퀄 어스·정거원통; 평면 지도는 경선을 돌림) · **시점 초기화**.

### 타임라인
- **지구의 시간**: 시간 범위(고도 격자: 전체 시대 / 최근 2.5만 년 / 최근 13만 년) 또는 시간 간격(지도마다 n단계 / 1 Myr).
- ← 더 과거 · ▶ 시대 순서 재생 · 더 현재 → · 시대 선택 메뉴 · `n / N` 시점 수 · 슬라이더.
- 슬라이더 위 색띠: 전체 시대는 기온 띠, 시간 창은 해수면 띠(13만 년 창은 PaleoMIST 곡선 점선 겹침).
- 지도가 없는 오래된 시점(750 Ma 이전)은 판 재구성만 보인다.

### 정보 패널 (오른쪽, "정보" 버튼)
- **인도–아시아 A–A′ 단면** 버튼(팝업).
- SELECTED TIME: 시대, 나이, 출처 제목, 평균 기온, 기온·식생·강수 범례, 해수면 값.
- **지형 음영** 선택, **해수면** 슬라이더(−150~+150 m, 시간 창에서는 잠김)와 **곡선 편차 적용**.
- **위치 핀** 목록: 오늘·지금 좌표, 판, "지금 …"(가운데로), ×, 쌍별 대원 거리.
- **지구 내부**: 지각 두께(CRUST 2.0, 현재만; 두께 색상 지도, 클릭 읽기, 단면 1×/5×) · 맨틀 근사 중첩(슬랩·맨틀 하부 구조·핵 기준 구, 원본 시점 80/60/40/20/0 Ma, 지표 불투명도, A–A′ 단면선) · **공통 지표 절개**(남·북 위도, 서·동 경도, 인도–아시아 프리셋, 절개 중심으로 이동).
- **판 재구성** 안내: 모델 인용, 기준틀, 도달 범위, 잠금 해제.
- 안내문(켠 레이어에 따라): 지형, 빙하(한계선·가정·모델 복원), 하천, 해수면 가정, 모형 기후, 기온, 마스크, 보간, 지도 없음, 해안선.
- **변환 방식과 자료**: 출처·라이선스 목록.

## 자료 경로 (브라우저가 받는 것)

| 경로 | 내용 |
|---|---|
| HTML 안 `json_script` | 시점 목록과 각 레이어 URL, 눈금, 곡선, 판 모델 목록, 문자열 |
| `/globe/fields/<id>.png` | 고도 격자 텍스처(해안 거리장 + 높이) |
| `/globe/temps/<id>.png` · `/globe/climate/<id>/<ka>.png` | 기온 · 모형 기후 |
| `/globe/ice/<id>.png` · `/globe/ice-low/<id>/<ka>.png` | 빙하 마스크 · 시점별 조각(1–80 ka) |
| `/globe/rivers/<id>.png` · `/globe/rivers-low/<id>.png` · `/globe/rivers-ice/<id>/<years>.png` | 하천 · 저수위 · 빙기(2.5–80 ka) |
| `/globe/coastlines/<age>.json` · `/plates/<model>/<layer>.json` | PaleoCoastlines · 판 회전·대륙 다각형 |
| `/mantle/assets/…` · `/crust/assets/…` · `/collision/data/…` | 맨틀·지각·단면 자료(gzip, 불변) |
| `/globe/maps/<id>.jpg` | 2002 원본 지도 — 운영에서는 비공개(404) |

전달 방식(HTML 한 번 → 시점마다 PNG 데이터 텍스처, GPU LRU 12장 → 켤 때만 JSON/gz)은
[globe-viewer.md](globe-viewer.md) "Runtime and data boundaries"를 따른다.

## 표시 원칙

발표된 자료(지도·격자·복원 조각·회전 모델), 이 프로젝트가 계산한 것(하천, 호수, 핀의 위치,
거리), 보간(지도 사이), 가정(해수면 what-if, 유사 빙하), 모델 결과(기온, 기후, PaleoMIST 빙상,
맨틀·지각)를 캡션과 안내문에서 구분한다. 자세한 근거는 [globe-viewer.md](globe-viewer.md)와
각 릴리스 devlog에 있다.
