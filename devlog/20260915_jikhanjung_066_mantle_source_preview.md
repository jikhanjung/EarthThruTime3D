# jikhanjung 066 — 지각 변형 자료 목록과 맨틀 3D 표면 실험

날짜: 2026-09-15 · 기준 버전: v0.10.5 · 브랜치: feature/crustal-deformation-mantle

## 목적과 구현 범위

[P03](20260915_jikhanjung_P03_crustal_deformation_mantle_coupling.md)의 첫 구현이다.
계획 문서 브랜치를 feature 브랜치로 바꾸고, 실제 자료를 내려받아 검사하는 경로와
발표된 맨틀 구조를 지구본으로 확인하는 `/mantle/` 화면을 만들었다.

지각 변형이나 대류를 자체 계산한 것은 아니다. 이번 범위는 자료 목록과 출처 고정,
공개된 3D 표면의 변환·표시다. 자세한 데이터 계약과 재현 명령은
[docs/geodynamics.md](../docs/geodynamics.md)에 기록했다.

## 실제 자료를 열어 확인한 것

- Müller 2019 v1.2 아카이브는 37,549,700 bytes, 117개 파일이다. 회전 파일 12개와
  최상위 GPML 변형 네트워크 feature 350개를 확인했다. GPML 내부에 중첩된 같은 이름의
  값 객체를 별도 네트워크로 세지 않는다. 이름·판 ID·유효 시기 문자열·파일 해시를 목록화했다.
- Greater India의 stretched mesh에는 16개 네트워크 feature가 있다. 그 파일의 유효 시기
  범위는 160–21.1 Ma이며, 이 파일 하나가 현재까지의 히말라야 변형을 제공하는 것은 아니다.
- Müller 2022 OPT1 저해상도 ParaView ZIP은 205,811,467 bytes다. 예상했던 온도 격자 대신
  이미 추출된 Slabs·Piles 표면을 담는다. 점 변수는 `Depth(km)`와 `NonDimDepth`이고,
  온도·속도 체적장은 없다. 온도 단면용 대형 NetCDF ZIP은 내려받지 않았다.
- ParaView 상태 파일의 시간 라벨은 `1000 - 20 × source_time`이다. 원본 번호 0–50은
  1000–0 Ma의 51개 시점이다. 파일 번호를 Ma로 잘못 읽지 않도록 이 식을 검사한다.
- 두 Zenodo API 기록은 CC BY 4.0을 명시한다. Müller 2019의 별도·동봉 License.txt도
  일치한다. 배포자의 MD5와 다운로드를 대조한 뒤 manifest에 SHA-256을 고정했다.

## 코드와 화면

`sources/geodynamics/`는 기존 판 회전 manifest와 분리했다. 기존
`fetch_paleodem.py --manifest`로 원본과 메타데이터를 재다운로드·검증할 수 있다.
`scripts/geodynamics.py`는 구조 목록을 만들고, `scripts/build_mantle.py`는 원본 ZIP에서
필요한 VTK 조각을 읽어 브라우저용 float32 위치·uint32 연결 정보를 만든다.

모든 시점에서 배열 길이, 점 인덱스, 삼각형·선 형식, 원본 시각과 깊이–반지름 일치를
검사한다. 슬랩과 하부 구조는 원본 삼각형을 유지한다. 판 경계도 같은 OPT1 묶음의
자료를 사용한다. PALEOMAP 표면과의 좌표계 정합은 하지 않았다.

`core/mantle.py`가 목록에 있는 파일만 제공하고, Three.js 화면에서 회전·확대·시점 선택과
세 레이어 켜기를 제공한다. 한국어·영문, 모바일 화면과 자료가 없는 환경의 안내를 포함했다.
기존 하단 메뉴에서 진입한다. 시점 사이의 보간, 온도 범례나 유속 화살표는 제공하지 않는다.

## 전송량 질문을 반영한 변경

사용자가 egress 비용을 지적하여 실제 파생 파일의 전송량을 측정하고 줄였다.
원본 격자·삼각형을 줄이는 대신 gzip 무손실 압축을 적용했다.

| 대상 | 압축 전 | gzip 전송 |
|---|---:|---:|
| 51개 시점 전체 | 174,819,852 bytes | 92,515,323 bytes |
| 현재 시점 | 3,848,452 bytes | 2,035,186 bytes |
| 시점 하나의 범위 | 약 1.48–3.92 MB | 약 0.77–2.08 MB |

약 47% 감소했다. 선택한 시점만 내려받고, 슬라이더 입력을 180 ms 기다려 지나가는
시점의 다운로드를 피한다. 진행 중인 이전 요청은 취소한다. 파일명에 내용 해시를
넣어 1년 immutable 캐시를 사용한다. 서버는 gzip 협상, 표현별 ETag와
`Vary: Accept-Encoding`을 제공한다. 화면은 이전 GPU 메시를 해제한다.

현재는 한 시점의 세 레이어를 함께 내려받으므로 레이어를 숨긴다고 전송량이 더 줄지는
않는다. 맨틀 자료만 보면 전체 탐색 1,000회가 캐시 없이 약 92.5 GB, 현재 시점만
1,000회가 약 2.04 GB다. 첫 방문의 Three.js·화면 코드, HTTP 부가량 등은 별도다.
이 수치는 요금 견적이 아니다. 공개 배포 전에 호스팅의 포함 트래픽과 과금 조건을 확인한다.

## 확인 결과

- `make check`: 통과, migration 변화 없음.
- `make test`: Django 테스트 57개 통과. 새 화면·허용 파일·누락/변조·gzip 협상을 포함한다.
- `tests/geodynamics_check.py`: 5개 통과. VTK 압축 블록, 연결 정보 오류와 중첩 네트워크 집계를 검사한다.
- `tests/mantle-browser.mjs`: 현재/80 Ma, 연속 입력의 마지막 시점, 지나간 시점의 요청 없음,
  gzip 응답, 오류 후 재시도, 레이어 선택, 모바일 폭과 영문 화면 통과. JS 오류 없음.
- 전체 51개 시점의 153개 레이어를 변환했고, 파일 길이·해시·gzip 왕복을 모두 검사했다.
- 데스크톱 스크린샷을 확인했다. 원본 ParaView 렌더와의 독립적 이미지 대조나 원래
  물리 모형의 타당성 검증까지 수행했다는 뜻은 아니다.

## 남은 범위

변형 네트워크의 실제 해석과 물질 격자 이동, 변형률·지각 두께·고도 계산은 다음 단계다.
맨틀 온도 단면은 별도 원본 자료가 필요하며, 서로 다른 판·맨틀 모형의 좌표계 변환도 남아 있다.
자체 솔버와 양방향 결합은 P03의 후속 연구 범위다.

원본과 파생 파일은 gitignored 로컬 자료다. 실험 자료는 아직 운영 배포 묶음에 넣지 않았고,
운영 서버·DB·CDN·스토리지는 변경하지 않았다. 버전 상승이나 배포도 하지 않았다.
