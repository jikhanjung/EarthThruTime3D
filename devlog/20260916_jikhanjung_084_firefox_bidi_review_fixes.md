# PR #47 — Firefox 검사 실패 처리와 Linux 실행

- macOS는 앱 경로, 그 외는 PATH의 firefox를 기본값으로 사용한다. FIREFOX_BIN은 유지했다.
- 시작 전체를 정리 구간으로 감싸 spawn 실패 시 명확한 오류와 프로필 정리를 보장했다.
- BiDi 명령 10초 제한, 연결 종료/실패 시 대기 명령 거부, 프로토콜 오류 처리를 추가했다.
- 실패 시 수집한 콘솔·네트워크 오류를 출력한다. 프로세스 종료를 기다린 뒤 프로필을 삭제한다.
- headless WebGL2가 없는 환경은 FIREFOX_HEADLESS=0과 Xvfb로 실행할 수 있게 했다.
- `make check`, Django 77개, JS 6개 파일 통과. BiDi 오류/시간 초과/연결 종료 회귀 검사를 포함한다.
- 존재하지 않는 실행 파일: 5초 내 명확한 종료, 임시 프로필 누수 없음 확인.
- Linux Firefox 146.0.1 + Xvfb에서 공개 사이트 검사 통과: 초기화, -60 m 구간(12.7 ka),
  20 ka 빙하·하천 선택, 콘솔·네트워크 오류 없음.
