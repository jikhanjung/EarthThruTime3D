# jikhanjung 070 — 80 Ma 메인 globe 맨틀 근사 중첩

날짜: 2026-09-15 · 브랜치: `feature/globe-mantle-overlay` · 상태: 1단계 구현, 운영 미배포

사용자는 [069](20260915_jikhanjung_069_mantle_frame_alignment.md)의 인도 위치 차이
약 3–4°를 대규모 탐색에서는 허용 가능한 수준으로 판단했다. 엄격한 정합과 구분되는
근사 중첩으로 진행하기 위해 [P05](20260915_jikhanjung_P05_globe_mantle_approximate_overlay.md)를 작성하고
그 1단계를 구현했다. 먼저 alignment [PR #35](https://github.com/jikhanjung/EarthThruTime3D/pull/35)를
main에 병합하고 새 브랜치를 그 기반으로 맞췄다.

## 구현

- 메인 정보 패널의 80 Ma 토글로 지표 아래 OPT1 Slabs/Piles를 표시한다.
  기본 꺼짐이고 선택 전 바이너리 요청은 없다. 80 Ma를 제공하는 PALEOMAP 계열만 지원한다.
- 80 Ma 아프리카 기준 회전과 화면 축 변환을 적용한다. 원본 깊이 배율은 ×1이며,
  지표 고도 과장을 맨틀에 적용하지 않는다. 인도 위치 P95 약 3°를 화면에 명시한다.
- 80°E·10°N 중심 각반경 45° 영역을 절개한다. 지표·선·지명을 함께 가리고,
  반대편 격자가 구멍으로 비치지 않게 했다. 맨틀도 같은 방사형 영역만 표시한다.
- 절개와 두 레이어의 독립 토글, 오류·재시도, 이전 시간·투영·카메라 복원을 제공한다.
  다른 연대·평면 투영 선택 시 모드를 해제하고, 취소된 요청의 늦은 적용을 막는다.
- 모바일에서 로딩 완료 후 정보 패널을 접고, 근사 중첩 캡션은 지도 위에 계속 둔다.
- 원본 아카이브와 두 메시 해시를 고정해 다른 자료 조합을 자동 적용하지 않는다.
  기존 API·gzip을 재사용하며 신규 원본 다운로드나 운영 데이터 재생성은 없다.

구조·변환식·재현 명령은 [구현 문서](../docs/globe-mantle-overlay.md)를 따른다.
A–A′ 공간 연결과 다섯 시점 동기화는 P05 2·3단계로 남겼다.

## 확인

- `make check`, Django 63개 테스트, 기존 JavaScript 회전·투영 및 신규 중첩 수치 검사 통과.
- 중첩 브라우저 검사: 최초 요청 0건, 80 Ma 메시 2건, 절개·레이어 토글, 평면 진입/복원,
  연대·투영 변경 시 해제, 실패/재시도, 요청 취소, 모바일·영문·PaleoDEM 표시.
- 기존 전체 globe 브라우저 회귀: 2002 지도, 아틀라스, 고도 지형, 판·해안선,
  투영·시간 간격·최근 빙기 범위·모바일·언어 전환 통과.
- 실제 WebGL 화면을 확인하고 로컬 `test-results/mantle-overlay-*.png`에 캡처했다.

운영 배포는 하지 않았다. 이는 시각화의 근사 중첩이며 지각 변형이나 맨틀 대류를 새로
계산한 결과가 아니다.
