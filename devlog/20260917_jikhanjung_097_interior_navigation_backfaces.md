# 절개 뒷면·지구본 조작·불투명도 색 변화 수정

## 문제

v0.18.0에서 지각·맨틀 절개 확대 시 반대편 지각이 사라졌다. 카메라 far plane이
아니라 지각 셰이더의 카메라 방향 기반 discard와 지표의 앞면 전용 렌더링 때문이었다.
지구본 pan은 비활성이고 기울이기는 고도 지형이 솟아 있을 때만 가능했다.
또 지표 불투명도가 100% 미만이면 지각이 투명 렌더 큐로 넘어가 지표 위에 갈색으로 덧칠됐다.

## 수정

- 절개 중 지표 양면을 렌더링하고 지각 안쪽·절개 벽의 반구 제거를 없앴다.
  절개 중 격자·경계선도 반구 제거 대신 깊이 검사로 가려진 부분을 판단한다.
- 내부 지각→절개 벽→지표 순서를 지정하고 투명 지각의 깊이를 기록한다.
  과학 자료·지각 두께·맨틀 메시 자체는 바꾸지 않았다.
- 모든 지구본에서 오른쪽/Ctrl·Meta 드래그는 이동, 휠·핀치는 확대,
  휠 클릭/Shift 드래그는 기울이기·방향 변경으로 통일했다.
- pan은 실제 그려지는 기울어진 카메라의 화면 축을 사용한다. Shift 제스처는
  OrbitControls보다 먼저 처리해 pan이 동시에 발생하지 않게 한다.
- 기본 근접 기울기와 수동 기울기를 고도 변위와 분리했다. 수동 조작 시작 시
  현재 보이는 각도부터 이어지고 reset은 pan·확대·기울기를 초기화한다.
- 기존 터치 두 손가락 기울이기도 모든 지구본에 적용한다.
- 맨틀 보기 저장·복원에 수동 기울기 상태를 포함한다. 평면 투영 조작은 유지한다.

## 검증

- `make check`: 번역 400개, Django 설정·마이그레이션 검사 통과.
- `make test`: Django 83개 통과. `npm test`: JavaScript 8개 파일 통과.
- Chromium: PaleoAtlas/PaleoDEM 각각 지각·맨틀 동시 표시, 근접 확대·pan·Shift 기울이기,
  pan/tilt 입력 충돌 방지, reset, 평면 투영 전환 검사 통과. 절개 안쪽과 확대 스크린샷 확인.
- Firefox 146.0.1: 지각 색·절개·5배·20→0 Ma, 하천·빙하·콘솔·네트워크 회귀 검사 통과.
- 새 회귀 검사는 `tests/interior-navigation-browser.mjs`. 불투명도 경계는 UI의 5% 간격을
  테스트에서만 1%로 바꾸어 100%와 99%의 동일 영역 픽셀 평균 차이를 측정한다.
  PaleoAtlas와 PaleoDEM 모두 RGB 채널 평균 변화가 255 중 0.18로, 기준 5 미만이다.
