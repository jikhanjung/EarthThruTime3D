# jikhanjung 048 — 지도 중심 화면

날짜: 2026-09-14

## 한 것

구글 맵이나 구글 어스처럼 지도를 화면의 주인공으로 바꿨다.

- 지도: 헤더 아래 창 전체를 채운다. 전에는 1440 px 틀 안에서 오른쪽 설명 패널과 나란히 놓였고,
  아래에 슬라이더 패널이 따로 있었다.
- 설명 패널: 지도 오른쪽 위에 떠 있는 오버레이로 바꾸고 "정보" 버튼으로 열고 닫는다.
  - 900 px 이상에서는 열린 채로, 좁은 화면에서는 닫힌 채로 시작한다.
  - 사용자가 고른 상태는 브라우저(localStorage)에 기억한다. 저장소를 막은 브라우저에서도
    동작은 같고 기억만 안 한다.
  - 내용이 길면 패널 안에서 스크롤되고, 조작 패널 위에서 멈춘다. 설명이 나타났다 사라져도
    지도 크기는 변하지 않는다.
- 조작 패널: 지도 위 도구 막대와 아래쪽 슬라이더 패널을 지도 아래쪽에 뜨는 패널 하나로 합쳤다.
  설명 패널에 있던 지질시대 선택과 ← → 버튼도 여기로 옮겼다.
  - 윗줄: 자료 선택, 투영, 자동 회전, 격자, 레이어 버튼, 판 경계선, 시점 초기화.
  - 아랫줄: 시간 간격, ← 더 과거 / 재생 / 더 현재 →, 지질시대 선택, 기온 색띠, 슬라이더.
  - 지형 음영과 해수면 선택은 표면 설정이라 설명 패널에 둔다.
- 해수면 곡선: 조작 패널에 두니 고도 격자 화면에서 패널이 높아져 지구본이 작아졌다.
  - 도구 막대의 "해수면 곡선" 버튼으로 여는 별도 오버레이로 뺐고, 처음에는 닫혀 있다.
  - 슬라이더 위에 붙어 있지 않으므로 지금 시점을 세로선으로 표시하고 양 끝 나이를 적었다.
- 지구본 틀 맞추기: 조작 패널이 지도 아래쪽을 가리므로, 가려지지 않은 높이에 구나 평면
  지도가 들어가도록 시야각을 넓힌다. 그리고 `setViewOffset`으로 화면을 가린 높이의 절반만큼
  올려 보이는 영역 가운데에 둔다. 패널 높이는 ResizeObserver로 따라가고, 가린 높이를
  CSS 변수 `--controls-space`로 넘겨 설명 패널과 해수면 오버레이가 그 위에서 멈추게 한다.
- 휴대폰과 짧은 가로 화면:
  - 조작 패널이 화면 폭에 맞고, 도구 막대는 한 줄을 유지하며 가로로 밀어 본다.
  - 짧은 화면에서는 눈금 설명과 범례를 숨긴다.
- 헤더와 바닥글:
  - 헤더는 "EarthThruTime3D · 시간을 돌려, 지구를 보다"에서 "Earth Thru Time v0.9.2"로 바꿨다.
    표시 이름은 `config/version.py`의 `APP_TITLE`이고, `APP_NAME`(EarthThruTime3D)은 식별자로
    탭 제목 등에 남긴다.
  - 바닥글의 버전은 뺐다. 배포 버전은 헤더에서 확인한다.
  - 브랜딩 가이드는 바닥글을 모든 페이지에 두라고 하므로, 지도 페이지에서는 오른쪽 아래의 작은
    출처 줄로 남겼다.

## 확인

- `make check`, `make test` 51개, `npm test` 13개, 브라우저 검사 전체 통과.
- 이전 배치를 전제로 한 브라우저 검사를 고쳤다.
  - 지도가 창을 채우는지, 정보 패널이 조작 패널 위에서 멈추는지, 접어도 지도 크기가
    그대로인지 본다.
  - 휴대폰에서는 조작 패널이 화면 안에 있는지, 가로 화면에서는 슬라이더가 보이는지 본다.
  - 해수면 곡선 오버레이가 처음에 닫혀 있고, 버튼으로 열고 닫히며, 조작 패널을 가리지 않는지 본다.
- 지도가 커지면서 소프트웨어 렌더러의 첫 텍스처가 늦어져 고도 격자 검사가 한 번 시간을 넘겼다.
  그 앞에 쓴 페이지를 닫고 첫 프레임 대기를 15초로 늘렸다.
- 데스크톱(1440, 1280), 휴대폰(390×844), 가로(844×390)를 캡처해 확인했다. 가로 화면에서
  "더 현재 →"와 시대 선택이 겹치던 것은 시대 선택이 칸 안에서 줄어들게 고쳤다.

## 남은 것

- 판 경계선 안내 문구는 "지구본 아래 두 번째 드롭다운"이라고 적혀 있다. 지금은 조작 패널
  안에 있어 틀린 말은 아니지만 더 정확히 고칠 수 있다.
- 폭 900~1000 px에서는 해수면 오버레이와 열린 설명 패널이 가로로 겹칠 수 있다.
