# jikhanjung 061 — 현재 구현에 맞춘 문서 정리

날짜: 2026-09-15 · 기준 버전: v0.10.3

## 변경

- `docs/globe-viewer.md`: 세 자료 시리즈, 시리즈별 시간 눈금, 12항목 LRU 텍스처 캐시,
  뷰어와 원본 공개의 별도 설정, 확장된 검증 범위를 반영했다.
- `docs/gplates-reference.md`: 회전 모델·판 ID·벡터 회전·평면 투영·레이어의 구현 상태를
  갱신했다. 판 회전으로 중심점을 옮기는 근사 보간과 아직 없는 per-plate 표면 회전,
  변형·융기·맨틀 솔버를 구분했다.
- `deploy/README.md`: 기본 90장과 비교용 17장, 고도·기온·해수면·빙하·해안선·판 모델의
  자료 묶음 구성을 정리했다. 필수 판 레이어와 선택 해안선 레이어를 구분했다.
- `docs/operations.md`: 기본 시리즈의 파일 존재가 이미 상태 점검의 도메인 조건임을
  반영했다. 상태 응답과 smoke는 모든 선택 레이어의 HTTP 응답·무결성을 검사하지 않는다.
- `sources/README.md`: 뷰어 활성화가 원본 이미지 공개를 뜻하지 않도록 설정 설명을 고쳤다.
- `devlog/README.md`: 현재 자료·보간·3D 지형·운영 백업과 남은 과제를 새로 정리했다.

## 확인

카탈로그, `core/globe.py`, 설정, 뷰어의 캐시 구현, 배포 패커와 smoke, 테스트 스크립트를
대조했다. 로컬 문서 링크와 diff 형식을 점검했다. 코드·자료·운영 설정은 수정하지 않았고,
실행 동작 변경이 없으므로 테스트 전체나 배포는 반복하지 않았다. 과거 개별 devlog는 보존했다.
