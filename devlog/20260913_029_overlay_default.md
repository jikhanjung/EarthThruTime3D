# 029 — 경계선 드롭다운 기본값 바로잡기

날짜: 2026-09-13

## 발단

페이지를 처음 띄우면 판 재구성 드롭다운에 "PALEOMAP 2016 (Scotese)"가 선택된 채로 보이는데, 경계선은
없고 마스크만 있었다.

## 원인

뷰어의 상태(`plateChoice`)는 처음에 비어 있어서 선을 그리지 않는다. 그런데 드롭다운 자체는 코드가 값을
정해 주지 않았다. 브라우저는 새로고침할 때 폼 요소의 마지막 값을 되살리므로(Firefox가 특히 그렇다), 전에
골랐던 모델 이름이 드롭다운에 남고 실제로는 아무것도 그리지 않는 어긋남이 생겼다. 마스크는 드롭다운과
관계없이 그리므로, 모델을 실제로 고르면 마스크와 경계선이 둘 다 보인다.

## 한 것

- 첫 항목 이름을 "겹치지 않음"에서 "경계선 없음"으로 바꾸고 기본으로 표시했다. 안내문도 맞췄다.
- 드롭다운과 해안선 체크박스에 `autocomplete="off"`를 두고, 시작할 때 코드가 드롭다운을 비운 값으로,
  체크박스를 끈 상태로 명시해 맞춘다. 화면에 보이는 값과 그리는 것이 항상 같게 했다.

## 확인

- 브라우저 검사에 더했다.
  - 첫 항목이 "경계선 없음"인지 본다.
  - PALEOMAP을 고른 뒤 새로고침하면 드롭다운이 비고 선이 없는지 본다.
  - PALEOMAP과 Merdith를 차례로 고르면 선이 그려지고 머리글에 "대륙 마스크"가 남는지 본다.
  - "경계선 없음"으로 돌리면 선이 사라지는지 본다.
