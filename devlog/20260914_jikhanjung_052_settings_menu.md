# jikhanjung 052 — 도구 줄은 필수만, 나머지는 메뉴로

날짜: 2026-09-14

## 한 것

제어판의 버튼·드롭다운 줄이 PC에서도 좌우로 스크롤됐다. 머지된 기능(3D 지형, 해수면 곡선 등)으로
버튼이 늘어 1280 px 폭에서도 넘쳤다.

- 도구 줄에는 ☰ 메뉴 버튼, 자료 선택, 투영, 시점 초기화만 둔다.
- 나머지는 ☰로 여는 설정 메뉴로 옮겼다. 자동 회전, 격자, 대륙 마스크, 기온, 3D 지형, 빙하,
  해수면 곡선, 판 경계선 드롭다운이다.
  - 메뉴는 제어판 위 왼쪽에 떠 있는 절대 위치 상자다. 제어판 크기를 바꾸지 않으므로, 열어도 지구본
    틀 맞추기(`--controls-space`)와 정보 패널 위치가 그대로다.
  - 지도를 조작하는 동안에는 열려 있고, ☰나 Esc로 닫는다. 바깥을 누르면 닫히는 방식은 여러 설정을
    지도를 보며 바꾸는 데 방해가 돼 쓰지 않았다.
  - 열림/닫힘은 정보 패널처럼 브라우저(localStorage)에 기억한다. 처음에는 닫혀 있다.
  - 요소 id는 그대로라 기존 스크립트 연결은 바뀌지 않았다.
- 지형 음영, 해수면 슬라이더, 화석 해안선은 설명 문구와 붙어 있어야 해서 정보 패널에 남겼다.
- 판 경계선 안내의 "지구본 아래 두 번째 드롭다운"을 "메뉴(☰)의 경계선 드롭다운"으로 고쳤다.
- 휴대폰에서 스크롤을 암시하던 도구 줄 오른쪽 끝 흐림은 이제 넘치지 않아 뺐다.

## 확인

- 고도 격자 화면(버튼이 가장 많다)에서 도구 줄의 내용 폭과 보이는 폭이 같다.
  - 데스크톱 1280: 946/946 px. 휴대폰 390: 352/352 px. 가로 844×390: 794/794 px.
- `make check`, `make test` 51개, `npm test` 13개, 브라우저 검사 전체 통과.
  - 브라우저 검사: 세 크기에서 도구 줄이 스크롤되지 않는지, 메뉴가 처음에 닫혀 있고 ☰와 Esc로
    열고 닫히는지 본다.
  - 기존 검사는 새 페이지마다 메뉴를 한 번 열고 진행한다. 이후 새로고침은 기억된 상태로 열린다.

## 남은 것

- 짧은 가로 화면에서는 열린 메뉴가 지구본 일부를 가린다.
- 해수면 곡선 오버레이와 열린 메뉴가 둘 다 왼쪽 아래에 떠서 겹칠 수 있다.
