# jikhanjung 058 — v0.10.1: 휠 클릭으로 기울이기

날짜: 2026-09-14

## 한 것

- 3D 지형(050)의 기울기·방향 조작(054)을 오른쪽 버튼에서 휠 클릭(가운데 버튼) 드래그로 바꿨다.
  Shift+드래그는 그대로다.
  - OrbitControls 는 가운데 버튼을 dolly 에 쓰지만 휠이 이미 그 일을 하므로
    `controls.mouseButtons.MIDDLE = null` 로 넘겨받았다. 평면 지도의 오른쪽 드래그 이동은 영향이 없다.
  - 제스처 안내가 "휠 클릭 드래그로 기울이기"로 바뀌었고 영어 번역도 맞췄다.
- v0.10.1 배포. 자료 묶음은 v0.9.4 이후 그대로다. prune 으로 v0.10.1·v0.10.0 만 남겼다.

## 확인

- `make test` 51개, 브라우저 검사 전체 통과. 브라우저 검사의 기울이기 항목은 가운데 버튼으로 끈다.
  첫 실행에서 언어 전환 뒤 페이지 로딩이 5초를 넘겨 한 번 실패했고, 재실행에서 통과했다. 이 변경과
  무관한 시간 문제다.
- 배포 뒤 `/healthz` 0.10.1, 서버 검사 통과, 새 스크립트에 가운데 버튼 처리가 있는지 확인했다.
