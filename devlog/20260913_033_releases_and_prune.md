# 033 — 오늘 배포와 정리

날짜: 2026-09-13

## 배포

같은 절차로 여섯 번 배포했다. 빌드 호스트에서 검사·테스트·묶음·이미지·컨테이너 검사, dolfinid로 올려
체크섬 확인, `deploy.sh`가 DB 스냅샷 뒤 교체와 스모크. 모두 통과했고 되돌린 적은 없다.

| 판 | 내용 | 기록 |
|---|---|---|
| v0.8.2 | PALEOMAP 2016 회전 모델을 드롭다운에 | 022 |
| v0.8.3 | 2016 PaleoAtlas 마스크 기본, 판 이름과 회전 이동 | 023, 024, 025 |
| v0.8.4 | 화석으로 고친 해안선 체크박스 | 027 |
| v0.8.5 | 경계선 드롭다운 기본값 "경계선 없음" | 029 |
| v0.8.6 | 평면 지도 회전, 1 Myr 간격 | 030, 031 |
| v0.8.7 | 헤더 한 줄, 보간 시점 시대 이름 | 032 |

v0.8.3에서는 `smoke.sh`가 바뀌어 호스트 파일을 비교한 뒤 그 파일만 교체했다. 이후에는 호스트 묶음이
그대로라 이미지와 데이터만 올렸다. 배포한 이미지 ID는 `deploy/README.md`에 있다.

024와 027에 "배포하지 않았다"고 적은 것은 각각 v0.8.3, v0.8.4로 배포됐다.

## 정리

`prune.sh`를 세 번 돌렸다. 마지막에는 v0.8.3~v0.8.5를 지워 469 MB를 되찾았고, dolfinid에는 v0.8.7(실행 중)과
v0.8.6(되돌리기용)만 남았다. 빌드 호스트에서도 같은 판만 남기고 이미지, `dist/`, `.build/`를 지웠다.
dolfinid 디스크는 82% 사용 중이다. 이 서비스 몫은 작고, 다른 서비스가 대부분을 쓴다.
