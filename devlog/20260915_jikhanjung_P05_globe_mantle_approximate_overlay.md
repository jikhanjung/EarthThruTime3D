# jikhanjung P05 — 맨틀 근사 중첩부터 단면·시간 통합까지

날짜: 2026-09-15 · 기준: v0.11.0 및 jikhanjung 069 · 상태: 1–3단계 구현·검증, 운영 미배포

구현 기록: [jikhanjung 070](20260915_jikhanjung_070_globe_mantle_overlay.md),
[jikhanjung 071](20260915_jikhanjung_071_globe_mantle_time_section.md).

## 결정과 목적

[P04](20260915_jikhanjung_P04_globe_mantle_section_integration.md)의 좌표계 검사에서
PALEOMAP은 OPT1과 엄밀하게 정합되지 않았다. 사용자는 대규모 구조를 rough하게
탐색하는 목적에서는 인도 위치 차이 약 3–4°를 허용할 수 있다고 판단했다.
이에 ‘다른 복원 모델의 근사 중첩’임을 명시한 탐색 모드를 먼저 만든다.
이는 기하 정합 검사 0.1°를 통과했다는 뜻이나 히말라야–섭입판의 정확한 연결을 뜻하지 않는다.
검사 기준과 제품에서 허용하는 시각화 한계를 구분한다.

## 1단계 — 80 Ma 근사 중첩과 지역 절개

- 메인 globe에서 명시적으로 켜는 모드로 제공한다. 기본은 꺼짐이며 선택 전 맨틀
  메시 요청은 없다. PALEOMAP 계열 지표와 80 Ma를 제공하는 시간 범위에서 사용한다.
- 선택 시 80 Ma와 구면 투영으로 이동하고 인도–아시아 지역을 바라본다. 종료하면
  이전 시간·카메라·투영을 복원한다. 다른 연대·투영으로 직접 이동하면 모드를 해제한다.
- 069의 80 Ma `OPT1→PALEOMAP` 아프리카 기준 회전과 화면 축 변환을 적용한다.
  원본 해시·시점·대상 기준틀과 행렬을 작은 런타임 설정으로 고정한다.
- 인도–아시아 중심의 구면 영역을 절개해 지표 아래 OPT1 Slabs/Piles를 보여 준다.
  절개는 표시를 가리는 기능이며 단층이나 실제 지각 경계를 나타내지 않는다.
- 지표의 기후·빙하와 격자·경계선·지명에도 절개를 적용한다. 지표 외관 비교를 위해
  절개를 끄거나 다시 켤 수 있게 한다. 맨틀 레이어는 개별 토글한다.
- 맨틀 반경·깊이를 보존하고 지표 고도 과장을 맨틀에 적용하지 않는다. 개념적 대류
  화살표, 지각 변형 시나리오, A–A′ 단면 자동 연결은 이 단계에 포함하지 않는다.
- 화면에 80 Ma, 근사 중첩, 색의 의미, 출처와 위치 차이를 표시한다. 로딩·오류·재시도,
  중단·재진입 시 오래된 요청이 복구된 지구본을 다시 절개하지 않게 한다.

완료 조건: 실제 메인 구면에서 80 Ma 지표와 맨틀을 함께 탐색할 수 있고, 회전·확대·
레이어 토글·절개·종료 복원이 동작한다. 잘못된 원본 조합은 활성화하지 않는다.
기본 요청 0건, 선택한 한 시점만 전송, 오류 복구, 모바일·영문 및 기존 globe 회귀를 검사한다.

## 2단계 — A–A′ 단면 연결

- 지구본에 단면선·끝점·방향을 표시하고 선택 시 기존 단면 패널을 연다.
- 원본 OPT1 85°E 단면을 유지할지, 목표 PALEOMAP 좌표에서 새 단면을 정의할지 명시한다.
  선·절단면·법선·반평면에 일관된 변환을 사용한다.
- 지표와 맨틀의 원본 연대·기준틀 및 근사 정렬임을 패널에서도 표시한다.
- 지표·맨틀·지각 설명 모형의 수직 배율을 구분한다. 지각 시나리오 융기를 PaleoDEM에
  더하지 않는다. 기존 독립 페이지와 팝업은 유지한다.

완료 조건: 지도에서 선택한 선과 실제 단면이 같은 위치를 나타내고 패널과 3D 화면이
같은 연대를 표시한다. 키보드·모바일에서 열기·닫기와 포커스 복귀를 검증한다.

## 3단계 — 다섯 원본 시점의 공유 시간

- 80·60·40·20·0 Ma마다 검증한 근사 변환을 사용해 메인 시간과 맨틀·단면을 연결한다.
- 원본 연결 구조가 다른 메시의 정점 보간은 하지 않는다. 다섯 시점의 단계적 전환부터
  제공하며 일반 지표 타임라인의 세밀한 간격은 유지한다.
- 요청 연대와 실제 표시 연대를 구분하고, 로딩 중 과거 메시를 새 연대처럼 표시하지 않는다.
- 시점 변경 요청 취소, 지연 처리, 상한 있는 캐시·GPU 해제와 전송량을 측정한다.

완료 조건: 다섯 시점에서 모든 뷰가 동기화되고 빠른 시간 변경·취소·자료 실패에도
상태가 일치한다. 1만 년 표시 tick과 물리 모사는 별도 후속 과제로 남긴다.

## 후속 구현 반영 (2026-09-15)

사용자 요청에 따라 2·3단계를 함께 구현했다. 원본 OPT1 85°E 단면을 유지하고,
연대별 변환을 메인 단면선에 적용했다. 팝업과 메인은 다섯 시점을 공유한다.
절개 중심·각반경 및 지표 불투명도를 조절할 수 있다. 이후 요청에 따라 맨틀의
절개 영역 제한을 제거하고 전 지구 구조와 회색 핵 참고 구를 표시한다.
핵은 위치·크기 참고이며 온도·유동 계산은 아니다. 상세 동작은
[구현 문서](../docs/globe-mantle-overlay.md)를 기준으로 한다.

연속 메시 보간, 이동 가능한 과학 단면, 대류 솔버는 이번 단계 밖이다.
