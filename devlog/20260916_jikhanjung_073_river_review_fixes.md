날짜: 2026-09-16 · 대상: PR #38·#39

## 검토와 변경

- #38 최신 import map 수정은 독립 `collision.html`의 import map을 보존한다.
  `make check`, `make test` 63개와 Chromium 단면·팝업 검사를 통과했다.
  Firefox 146.0.1을 Xvfb·소프트웨어 렌더링으로 실행해 지구본, 맨틀 중첩,
  연결 팝업, 독립 단면, 독립 맨틀의 초기화도 확인했다. 검토 중 다른 작업자가 main에 병합했다.
- #39는 처음 검토한 커밋이 #38의 옛 변경을 포함했으나, 갱신된 `2a6da1f`는
  최신 main에 기반하며 독립 단면의 import map을 보존한다.
- 하천 굵기 필드의 `np.roll`은 위도까지 순환했다. 북쪽 끝 행에 값 255를 넣으면
  남쪽 끝 행에 166, 그 다음 행에 77이 생기는 것을 재현했다. 위도 경계 밖 표본을
  제외하고 경도의 날짜변경선 연결은 유지했다. 양극·경도 경계 회귀 검사를 추가했다.
- 0.1° 원자료와 2048×1024 계산 격자(적도 약 20 km), 과학적 복원 정확도를 구분하도록
  한국어·영어 화면 안내와 구현 문서를 보완했다. 잠재 배수 경로를 실제 고대 하천으로
  단정하는 스크립트 설명을 고쳤다. 현재 하구 비교는 고대 경로의 정확도 검증이 아니다.
- 자료 라이선스 목록에 잠재 배수망 텍스처를 명시했다.

## 자료와 배포

검토 도중 추가된 `a78464e`의 저수위 배수도 통합했다. 수정된 스크립트로 0 Ma의
0 m·−130 m 텍스처를 다시 만들었다. −130 m 계산은 14초, 최대 유역 9.99 Mkm²였다.
이번 검증에서는 0 Ma만 다시 만들었다. 앞서 작성자가 생성한 109장 전체는 이번 수정본으로
재생성한 묶음이 아니므로, 배포 자료를 준비할 때 수정 스크립트로 다시 생성해야 한다.
운영 배포나 원본 자료 변경은 수행하지 않았다. 저수위 표시는 정상·최저 해수면에서 계산한 두 장의 필드를 섞는 표시이며, 모든 중간
해수면에서 다시 계산한 경로는 아니다. 실제 강의 복원, 빙하 아래 흐름, 호수·내륙 분지의
검증은 후속 과제다.
