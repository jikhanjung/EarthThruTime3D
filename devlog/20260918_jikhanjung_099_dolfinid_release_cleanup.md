# dolfinid의 오래된 배포 파일 정리

## 범위와 확인

사용자 요청으로 dolfinid-2의 EarthThruTime3D 배포 파일을 정리했다.
실행 중 컨테이너가 v0.18.1이고 정상 상태인 것을 확인했다. 서버의 prune.sh 해시가
저장소 deploy/host/prune.sh와 일치함을 확인하고 `DRY_RUN=1 KEEP=2`로 대상 목록을 읽었다.
현재 v0.18.1과 직전 롤백용 v0.18.0을 보존했다.

## 실행 결과

`/srv/earththrutime3d`에서 `KEEP=2 bash prune.sh`를 실행했다.
삭제한 11개 버전은 v0.17.0, v0.16.0, v0.15.1, v0.15.0, v0.14.1, v0.14.0,
v0.13.0, v0.12.0, v0.11.0, v0.10.5, v0.10.4다.

- 삭제 대상: 해당 버전의 프로젝트 Docker 이미지, `data/<version>`,
  `~/earththrutime3d-release`의 이미지·자료·호스트 tar.gz 및 SHA256SUMS.
- v0.10.4/0.10.5 이미지는 사전에 없었으며 남아 있던 파일만 정리했다.
- 프로젝트 외의 Docker 이미지·캐시에는 전역 prune을 실행하지 않았다.
- DB, 백업, secrets, 운영 스크립트와 두 보존 버전의 자료는 유지했다.
- 확보량: **8,099 MiB (약 7.9 GiB)**. 여유 공간 **16.4 GiB**.
- 파일시스템 사용률: **86% → 72%** (`df -h` 여유 표시는 8.6G → 17G).
- 자료 디렉터리: **4.7G → 856M**. 배포 묶음 디렉터리: **4.2G → 675M**.

## 정리 후 검증

- dry-run 재실행: 추가 삭제 대상 0개.
- 프로젝트 이미지 제목 label로 조회한 이미지도 v0.18.1/v0.18.0 두 개뿐이다.
- 프로젝트 컨테이너는 v0.18.1 하나이며 healthy, 재시작 없이 기존 실행 유지.
- v0.18.0 이미지와 자료 manifest가 남아 있어 기존 rollback 명령을 사용할 수 있다.
- smoke.sh 통과: 0.18.1 / ok, DB·스키마 정상, PaleoAtlas 필수 자료 90개 중 누락 0.
- 애플리케이션 코드나 배포 동작 변경은 없다.
