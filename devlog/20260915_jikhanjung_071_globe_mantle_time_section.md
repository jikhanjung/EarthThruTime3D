# jikhanjung 071 — 전 지구 맨틀·핵 표시와 시간·단면 연결

## 배경과 변경

070의 80 Ma 근사 중첩을 확인한 뒤, 절개 위치·지표 투명도·80 Ma부터 현재까지의
전환과 A–A′ 단면 연결을 진행했다. 사용자가 절개 시 맨틀을 영역별로 자르지 말고
전 지구 구조와 핵을 함께 보여 달라고 요청하여 해당 표시 제한을 제거했다.

- Slabs/Piles 전체와 반지름 0.546 지구 반경의 회색 핵 참고 구를 표시한다.
  각각 토글 가능하며 핵은 계산 자료가 아닌 크기·위치 참고임을 범례에 명시한다.
- 지표만 절개한다. 중심 경도·위도·각반경과 지표 불투명도를 조절할 수 있다.
  지표 격자·해안선·이름표에도 절개와 투명도가 적용된다.
- 80·60·40·20·0 Ma의 감사 행렬과 메시 해시를 새 설정에 고정한다.
  메인 시간과 단면은 다섯 원본 시점을 공유하며 중간 입력은 가까운 원본으로 맞춘다.
  원본 연결 구조가 다른 메시를 보간하지 않는다. 모드 중 자동 재생은 비활성화한다.
- OPT1 원본 85°E, 40°S–60°N 단면을 연대별로 변환해 분홍 A–A′ 선으로 표시한다.
  선 또는 버튼으로 같은 연대의 팝업을 열고 양방향 시간 변경을 동기화한다.
  절개 위치 변경은 이 고정 단면을 옮기지 않는다. 연결 모드의 지역 지형에서는
  별도 기준틀의 85°E 선을 숨겨 메인 분홍 선과 혼동하지 않게 한다.
- 요청 지연·취소와 GPU 해제를 적용하고, 로딩 중 과거 메시·단면을 숨긴다.
  오류·재시도·빠른 시간 변경에서 서로 다른 연대가 같은 자료처럼 표시되지 않게 한다.

## PaleoCoastlines 높이 보정

해안선이 지표에서 멀리 떠 있는 문제는 기존 0.007 지구 반경 표시 여유(약 45 km)가
지형 높이에 더해졌기 때문이다. 선 위치를 정규화한 뒤 지형 높이와 구면 메시 해상도에
따른 작은 여유만 적용하도록 바꿨다. 확대 시 지형 과장이 꺼져 있어도 상세 구면을 쓴다.
확대 브라우저 검사에서 표시 여유는 0.0000396 지구 반경(약 252 m)이었으며,
스크린샷에서 지표에 가깝게 그려지는 것을 확인했다. 이 여유는 실제 지형 고도가 아니다.

## 범위와 다음 작업

새 대용량 원본 다운로드는 없으며 선택한 연대의 기존 메시 두 개만 요청한다.
핵은 클라이언트에서 생성한다. 여전히 근사 좌표 정합이며, 맨틀 대류·지각 변형을
새로 계산하거나 1만 년 해상도로 보간한 결과가 아니다.
운영 배포 전 단계이며 개발 미리보기에서 확인한다. 정량적 운동장과 이동 가능한
과학 단면은 이후 작업으로 남긴다.
