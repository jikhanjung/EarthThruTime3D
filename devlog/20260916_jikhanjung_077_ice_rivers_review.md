# PR #44 — PaleoMIST 하천 검토 및 보완

## 범위

PaleoMIST 1.0의 빙하 표면을 이용한 잠재 배수망 PR #44를 검토했다.
현재 해수면에 대응하는 빙기 계산 결과를 고르는 기능이며, 모든 지질시대의 실제
하천을 복원한 것은 아니다. 빙하 표시 자체는 NADI-1/DATED-1을 계속 사용한다.

## 수정

- 원본 ZIP을 삭제한 뒤 폴더 존재만으로 `--verify-only`가 성공하던 문제를 수정했다.
  검증한 ZIP에서 파일별 SHA-256·크기와 원본 ZIP 지문을 기록하고, 이후 파일을 다시 검증한다.
- 임시 디렉터리에 추출·검증한 뒤 게시한다. 기존 폴더가 불완전하거나 파일이 다르면
  원본 ZIP을 삭제하지 않는다. 경로 이탈도 거부한다.
- 과거 방식으로 추출한 폴더에는 기록이 없으므로 검증된 ZIP이 다시 필요하다.
  이 동작과 재검증 방법을 자료 및 뷰어 문서에 반영했다.
- 선택 자료인 `rivers-ice.json`이 손상되거나 연대·해수면 순서가 잘못돼도
  전체 지구본 페이지가 실패하지 않게 하고 기본 하천으로 돌아가도록 했다.

## 검증

- `make check`, `make test`: 통과, Django 77개 테스트.
- `npm test`: 기존 PR 기준 5개 테스트 파일 통과.
- `.venv/bin/python tests/rivers_check.py`: 8개 수치 테스트 통과.
- Firefox: 하천 PNG, 켜기/끄기, 저해수면, 두 시간 범위, 모바일 폭, 한영 표시 통과.
- 브라우저 응답에만 합성 빙하 하천 메타데이터를 넣어 첫 구간/중간 구간 보간,
  정확한 경계, 가장 오래된 결과 유지, 현재 복귀를 검사했다. 모두 통과.
- 실제 PaleoMIST 3.5 GB 원본은 이 환경에 없어 10개 빙하 하천 격자를 다시 생성하지 않았다.
  합성 브라우저 검증은 실제 빙하 수치 결과 검증을 대신하지 않는다.
- 최신 main과 열린 PR·이슈를 다시 확인했다. #44만 열려 있고 main 변경은 없었다.
