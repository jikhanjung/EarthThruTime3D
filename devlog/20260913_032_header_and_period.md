# 032 — 헤더 한 줄로, 보간 시점은 그 나이의 시대로

날짜: 2026-09-13

## 한 것

- 페이지 머리를 한 줄로 줄였다. 왼쪽 "EarthThruTime3D" 옆에 작은 글씨로 페이지 제목만 둔다.
  - 위쪽 "프로젝트 소개" 링크는 뺐다. 아래 바닥글에 같은 링크가 있다.
  - 뷰어 위의 큰 제목과 "EARTH THROUGH TIME / PALEOMAP" 머리글, "3D 고지리 탐색" 표시도 뺐다. 그 표시는
    누를 수 있는 버튼처럼 보이지만 기능이 없어 헷갈렸다.
  - 제목은 헤더 안의 `h1`으로, 글씨는 0.95rem으로 작게 했다. 다른 페이지는 제목 없이 이름만 나온다.
- 오른쪽 패널의 시대 이름:
  - 원본 지도에 해당하는 시점은 지도의 이름을 그대로 쓴다.
  - 두 지도 사이의 보간 시점은 "A → B" 대신 그 나이가 속한 시대 하나를 쓴다. 2016 지도 이름을 붙일 때 쓰는
    국제연대층서표(ICS 2023/09) 경계를 페이지에 넘겨 같은 표로 정한다. 예를 들어 250~255 Ma 사이
    252.5 Ma는 "후기 페름기"다.
  - 최후 빙기 최성기와 현재 사이를 위해 표에 홀로세(1만 1,700년 전부터)를 더했다.
  - 지구본 위 머리글, 슬라이더의 읽기용 설명, 상태 문구도 같은 이름을 쓴다.
- 현재의 나이는 "현재" 대신 "0 Ma"로 적는다. 시대 이름 칸은 계속 "현재"다. 지질시대 선택 목록도
  "현재 · 0 Ma"로 나온다.

## 확인

- Django: 첫 페이지에 작은 제목이 있고, "3D 고지리 탐색", "EARTH THROUGH TIME", 위쪽 메뉴가 없는지,
  252.5 Ma가 후기 페름기로 나오는지 본다.
- 브라우저:
  - 250~255 Ma 한가운데 눈금에서 시대 이름이 "후기 페름기" 하나만 나오는지 본다.
  - 현재에서 나이가 "0 Ma", 시대가 "현재"인지 본다.
  - 헤더에 메뉴와 표시가 없고 높이가 한 줄(80 px 미만)인지 본다.
