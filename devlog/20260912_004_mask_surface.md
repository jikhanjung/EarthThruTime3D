# 004 — 마스크로 칠한 지구본

날짜: 2026-09-12

## 한 일

지구본 표면을 원본 지도 대신 대륙 마스크로 그리는 옵션을 붙였다. 도구 막대의
`대륙 마스크` 버튼으로 켜고 끈다. 육지는 모래색, 바다는 짙은 남색 두 가지로만 칠한다.
색을 원본 팔레트와 일부러 다르게 골랐다. 분할 결과를 원본 지도로 오해하지 않게 하려고.

## 구현

Django가 `/globe/masks/<id>.png`로 마스크를 내보낸다. 허용 목록과 뷰어 활성화 조건은
원본 지도와 같다. 브라우저는 마스크를 원본과 똑같은 Mollweide 역샘플링에 통과시킨 뒤
중간 회색값에서 자른다. 쌍선형 보간이 만든 흐린 경계를 다시 또렷한 해안선으로 되돌린다.

버튼은 마스크 파일이 하나라도 있을 때만 나타나고, 마스크가 없는 시대에서는 비활성이다.
마스크는 gitignore된 `data/derived/`에 있으므로 새로 받은 저장소에서는 분할 스크립트를
돌리기 전까지 원본 지도 지구본만 보인다. 텍스처 캐시 키에 표시 모드를 넣어 두 표면이
서로 덮어쓰지 않게 했다.

## 표시하는 내용

마스크 모드는 해석이다. 인쇄된 색에서 갈라낸 육지와 바다이고, 대륙붕은 바다, 빙상은
육지로 친다. 원본이 그린 해안선 자체가 아니다. 정리 연산에서 가장자리 화소가 깎이는
것도 그대로 반영된다. 이 내용을 모드가 켜져 있는 동안 오른쪽 패널에 띄운다.
원본 미리보기는 모드와 무관하게 항상 원본 지도를 보여준다.

## 검증

- Django 테스트 10개 통과. 마스크 경로 허용 목록, 뷰어 비활성 시 404, 마스크 파일이
  없을 때 404, 마스크가 없으면 버튼이 렌더되지 않는 것까지 확인했다.
- 브라우저 검사에 마스크 토글을 추가했다. 두 표면의 캔버스 픽셀이 실제로 달라지는지,
  시대를 바꿔도 모드가 유지되는지, 안내 문구가 뜨고 사라지는지, 원본 미리보기가
  그대로인지 확인한다. 17장 렌더와 기존 검사도 함께 통과한다.
- 데스크톱 캡처를 `data/screenshots/globe-mask.png`에 저장하고 직접 확인했다.
