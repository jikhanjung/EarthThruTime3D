# wwolf P02 — 해류와 해수면 온도: 현재에서 캄브리아기까지

날짜: 2026-09-23 · 개정: 2026-10-03(jikhanjung P10과 나눔, #89) · 기준 버전: v0.26.0 ·
상태: 계획. 1단계(현재 평균 해류의 검증)는 [wwolf 020](20261003_wwolf_020_ecco2_drifter_check.md)에서 쟀다.

## 목적

지구본에 표층 해류를 올릴 수 있는지, 현재부터 541 Ma까지 어디까지 정직하게 보일 수
있는지를 정한다. 하천 층(wwolf 007)이 남의 모형 출력 대신 PaleoDEM 위에서 **잠재 배수망**을
직접 계산했듯, 해류도 공개 자료와 직접 계산을 나란히 놓고 고른다.

**P10과의 나눔 (2026-10-02, #89).** 현재(0 Ma)의 평균 표층 흐름은
[jikhanjung P10](20261002_jikhanjung_P10_present_earth_in_flux.md)이 맡아 v0.24.0에 실었다. ECCO2 cube92
1992–2018 평균을 `static/core/flux.js`의 입자로 그리고, 주소는 `currents=flow`다. 이 계획은 그 평균의
검증, 해수면 온도, 과거의 바다, 시간 창을 맡는다. 과거 해류는 P10의 형식과 입자 그리기를 그대로 쓴다.

### FOAM 세트의 성격

모든 시각이 CO₂ 2240 ppm, 태양 1368 W/m², 이심률 0·최소 경사, 육지는 암석 사막으로 같고
**지리만 바뀐다**. 그 시대의 기후가 아니라 대륙 배치가 해류에 주는 효과를 보여 준다.
기록에 연결된 논문이 없어 아직 어느 논문의 실행인지 확인하지 못했다.

### HadCM3L 해양 출력 (2026-10-03 확인)

`scotese_02`의 두 시각(541 Ma `texqe`, 0 Ma `texpa1`)의 파일을 평가용으로만 읽었다(재배포 없음).
- `<run>o.pgclann.nc`(연 기후값, 전층): `ucurrTot_ym_dpth`·`vcurrTot_ym_dpth`(cm/s, 20층 5 m–5.2 km),
  `W_ym_dpth`(19층), `temp_ym_dpth`, `salinity_ym_dpth`, `mixLyrDpth_ym_uo`, `streamFn_ym_uo`(순압),
  `agewater_ym_dpth`(단위 없음, 안내서의 "Age of Ocean Water"). 격자 96×73(속도는 96×72).
- `merid_ocn/<run>o.meridclann.nc`: 자오면 뒤집힘 흐름함수 `Merid_Global`·`Merid_Atlantic`·`Merid_Indian`·
  `Merid_Pacific`(Sv, 21층 × 72위도).
- 시각마다 그 시기의 CO₂로 돌린 실행이라 FOAM(28장, 고정 CO₂)보다 과거 지도의 주 자료로 맞다. 다만
  모든 시각의 목록은 확인하지 않았고, 쓸 수 있는지는 Bristol의 답에 달렸다.
- PhanDA 기록에는 Valdes 2021의 두 계열이 다 있다: `scotese_02`(Foster et al. 2017 CO₂)와
  `scotese_spinupa`(그 곡선을 매끈하게 한 CO₂). 논문은 후기 백악기–신생대의 심층 수온에서 매끈한 CO₂
  쪽이 "particularly good"이라 했다. 어느 계열을 쓸지는 #6의 문의가 묻는다.

### 0 Ma 비교 (측정, 2026-10-03 개정)

세 자료를 부표 연평균의 1° 점에서 비교했다. 관측 속력 2 cm/s 이상이고 두 모형 모두 값이 있는 28,721칸,
위도 가중. 방법과 서안 경계류 표는 [wwolf 020](20261003_wwolf_020_ecco2_drifter_check.md),
스크립트는 `scripts/score_currents.py`.

|---|---|---|---|
| 방향이 90° 안 | 91 % | 73 % | |
| 열대 밖 / ±15° 안 | 89 % / 93 % | 80 % / 58 % | |
| 방향이 45° 안 | 77 % | 48 % | |
| 동서 성분 부호 일치 | 84 % | 69 % | |

| 적도 태평양 2°S–2°N, 160°E–100°W `u` | −0.33 | −0.50 | −0.21 |
| 남극 순환류 50–60°S `u` | +0.11 | +0.01 | +0.14 |
| 멕시코 만류 35–40°N, 75–60°W `u` | +0.11 | +0.04 | +0.21 |

해석: FOAM은 순환의 큰 방향과 적도 해류는 잡지만 서안 경계류와 남극 순환류는 거의 없다(2.8° 격자,
온실 기후, 계절 없음). ECCO2는 방향이 관측과 대체로 맞고 세기는 관측의 절반에서 4/5다. 처음 판의
적도 태평양 값(−0.54, 관측 −0.25)은 상자 경계를 적지 않아 다시 낼 수 없었다. 위 값은 적힌 상자의 것이다.

### PaleoDEM의 바다

1° 격자 기준 해양 비율 0.66–0.78, 200 m보다 얕은 바다 5–6 %. 200 Ma쯤보다 오래된 지도는
해저가 −3,700 m 부근의 평평한 심해저이고(서로 다른 수심값 93–95개, 신생대·중생대 후기는 150개
남짓) 해구와 해령이 없다. 해저 지형을 쓰는 계산은 이 시대에 근거가 없다.

### 해수면 온도와 난류·한류 (2026-09-23 추가, 2026-10-03 고침)

**해수면 온도 자료가 CC BY로 있다.** PhanDA의 모형 사전 분포("PhanDA HadCM3L Model Priors", Zenodo 8237751,
라이선스 `cc-by-4.0`을 API에서 읽음)는 Valdes 2021 등의 HadCM3L 실행을 변수별로 올려 둔 것이다. 기록의
작성자는 Judd, Tierney, Lunt, Montañez, Huber, Wing, Valdes 일곱이다(처음 판은 다섯으로 잘못 적었다).
모음 8개(`scotese_02`, `06`, `07`, `08`, `2co2a`, `4co2a`, `solara`, `spinupa`) × 변수 4개(`tos` 해수면 온도,
`so` 염분, `tas` 기온, `pr` 강수)이고, 각 zip에 109시각 × 5개(M1–M5, 각 실행의 마지막 100년을 20년씩
나눈 다섯 평균)가 든다. `scotese_02`의 `tos`는 291 MB, 파일 하나 1.2 MB, 96×73(3.75°×2.5°), 12개월,
변수 `temp_mm_uo`(°C). 시각은 PaleoDEM과 같은 109개(0, 4, 11 … 541 Ma).
[devlog 037](20260913_037_paleotemperature.md)과 `docs/globe-viewer.md`가 "라이선스가 없다"고
적은 것은 동화 결과 PhanDA 저장소이고, 이 사전 분포 기록과는 다르다.

0 Ma, M1–M5 연평균을 부표 해수면 온도(1°)와 비교(측정, 29,733칸, 위도 가중):
편차 −0.15 °C, RMS 1.23 °C, 상관 0.991.

**난류·한류 색.** 기준은 부표 해수면 온도에서 같은 위도의 바다 평균을 뺀 부호, 대상은 5 cm/s
넘게 흐르는 칸(|이상| > 0.5 °C, |위도| > 10°).

| 색을 정하는 방법 | 일치 |
|---|---|
| 지도책 규칙: 극 쪽으로 흐르면 난류, 적도 쪽이면 한류 | 57 % |
| FOAM 0 Ma 표층 수온의 위도 이상 | 64 % |
| 저장소의 기온 층(Scotese 2021, `tas`)의 위도 이상 | 89 % |
| PhanDA 사전 분포 `tos`의 위도 이상 | 92 % |

이름 있는 해류 11개에서 기온 층은 쿠로시오와 아굴라스를 틀렸다(1° 기온에 육지가 섞인다).
과거 시각에서는 모두 모형이므로 이 일치율은 0 Ma에만 성립한다.

**#6과의 관계.** 같은 기록의 `pr`이 #6이 기다리던 Valdes 2021 강수다. CC BY 4.0을 그대로 따를지,
어느 계열을 쓸지는 저장소 주인이 Bristol에 보내는 문의(#6) 1항에 들어갔다.

## 직접 계산: 바람이 만드는 잠재 해류

교과서 이론을 PaleoDEM 해안선마다 푼다.

- **Sverdrup 균형 + 서안 경계층(Stommel 1948 / Munk 1950)**: 바람 응력의 회전에서 깊이 적분
  흐름함수 ψ. `β ψ_x = curl τ / ρ₀ − r ∇²ψ (+ A ∇⁴ψ)`를 SciPy 희소 행렬 하나로 푼다.
  1°에서 미지수 약 6.5만 개, 지도 한 장에 수 초(추정).
- **Godfrey 1989 섬 규칙**: 대륙과 섬마다 ψ를 상수로 두고 순환 조건 하나씩. 인도네시아
  통과류, 남극 둘레 흐름, 통로가 열리고 닫히는 효과가 여기서 나온다.
- **Ekman 표층 흐름**: 바람 응력에서 바로 구한다. 1/f가 커지는 ±5° 안은 줄인다.
- **바람**: 무역풍·편서풍·극동풍의 동서 대칭 이상화 분포. 해들리 순환 폭은 처음에는 현재값
  하나로 두고, 바꾸는 것은 나중의 선택으로 남긴다.
- **바닥**: 평평하게 두고 얕은 바다(200 m보다 얕음)는 가린다. 순압 흐름은 f/H 등고선에
  지나치게 끌리고, 200 Ma보다 오래된 해저는 어차피 그림이다.

이론상 게어(환류)의 경계는 바람 회전이 0인 위도를 그대로 따르고, 어떤 게어와 통로 해류가
생기는지는 대륙 배치가 정한다. 바람을 바꾸면 경계가 몇 도 움직이고 세기가 달라진다.
Scotese 지리 시리즈에 이 방법을 돌린 발표 결과는 찾지 못했다. 비교할 기준 출력이 없다는
뜻이므로 0 Ma 검증이 유일한 근거가 된다.

**못 보이는 것**: 열염 순환과 심층류, 계절풍과 계절 반전(소말리 해류), 적도 잠류.
남극 순환류는 평평한 바닥 모형에서 세기가 틀리므로 **경로와 방향만** 보인다.

## 단계

### 1. 현재 평균 해류의 검증 (끝남)

현재 해류 층은 P10이 냈으므로 이 단계는 검증이 되었다. ECCO2 평균을 부표 연평균과 P02의 지표로 비교해
[wwolf 020](20261003_wwolf_020_ecco2_drifter_check.md)에 남겼다(위 표). `sources/drifters.json`은 이 검증의
기준으로만 쓰고, 처음 판에 적었던 `/globe/currents/<id>.png`, `#current-note`, 정적 무늬는 하지 않는다.

### 2. 0 Ma 계산의 시험 (여기서 갈림)

- `scripts/build_currents.py`: 위 계산, 0 Ma만.
- `scripts/score_currents.py`로 FOAM·ECCO2와 같은 칸, 같은 지표로 비교해 기록(wwolf 번호). 이름 있는
  서안 경계류 다섯(멕시코 만류, 쿠로시오, 브라질, 동오스트레일리아, 아굴라스)이 맞는 해안에 서는지도 본다.
- 기준: 열대 밖 방향 90° 안 비율이 FOAM의 80 %보다 낫고 서안 경계류가 맞는 쪽에 서면 계산을
  과거 지도의 주 자료 후보로 쓴다. ECCO2(89 %)는 넘을 기준이 아니라 상한의 참고값이다.
- `tests/currents_check.py`: 닫힌 사각 분지에서 서쪽 강화 게어가 생기는지, 섬 하나의
  순환이 섬 규칙 값과 맞는지.

### 3. 과거 지도 (P10의 형식과 그리기)

- **주 자료**: Bristol이 허락하면 HadCM3L 해양 출력(정지점마다, 그 시기의 CO₂), 아니면 2단계의 결론에
  따라 직접 계산 또는 FOAM 28장. FOAM은 어느 경우에도 시대별 방향 일치 표에 남긴다.
- **형식**: P10과 같은 PNG. R = u, G = v를 대칭 범위(`-M·128/127 .. M`, 코드 128이 0)로, B = **그 지도의
  바다**(PaleoDEM 해안선). 모형의 흐름은 지도가 바다로 그리는 칸까지 가까운 모형 칸으로 넓힌다. FOAM의
  2.8° 해안선은 PaleoDEM과 92–95 % 칸에서만 맞는다.
- **그리기**: `flux.js`가 0 Ma에서만 그리는 대신 지금 그려진 프레임에서 장(field)을 찾게 넓힌다.
  과거의 장은 프레임마다(`frame.currents`), 현재는 지금처럼 카탈로그에서. 두 정지점 사이에서는 가까운
  쪽의 장을 지도와 함께 옮기고(산맥 기호와 같은 이유: 슬라이더에 묶으면 대륙보다 앞서 간다), 장이 없으면
  지금처럼 `data-flux="unavailable"`. 이 확장은 과거 해류 PR에 들어간다(저장소 주인은 그 사이 `flux.js`를
  고침만 한다).
- **화면**: 연대 아래 시점 줄에 시대마다 출처, 예: "FOAM 모형, 100 Ma", "잠재 해류(계산)". 주소는 어느
  시대에서나 `currents=flow`.
- 화면 문구는 자료에 맞춘다. 계산을 쓰면 "이상화한 바람이 만드는 표층 해류(잠재)", 심층·계절풍이 없음,
  남극 순환류는 방향만, 얕은 바다는 가림.

### 해수면 온도 층 (1–3단계와 따로 설 수 있다)

- `sources/`에 Zenodo 8237751의 `tos` zip 하나를 SHA-256으로 고정. 어느 계열인지는 #6의 답을 따른다.
- 빌드: M1–M5 연평균(월별은 나중), 정지점마다 가장 가까운 시각, 기온 층처럼 그레이스케일
  텍스처 하나. 바다만 칠하고 육지는 기존 바탕.
- 모형 격자의 육지 경계는 PaleoDEM 해안선과 다르다. 해안 칸은 가까운 바다 값으로 채우고
  PaleoDEM 해안선으로 자른다(`build_climate.py`가 바다를 가까운 육지로 채운 것의 반대).
- 화면: 기온 토글 옆 `#sst` 또는 기온 층의 "바다" 선택, 같은 발산 색표. 해류를 켜면
  이 값의 위도 이상이 해류 색(빨강·파랑)을 정한다.

### 4. 시간 창 (나중)

0–22 ka는 TraCE, 6·21·127 ka는 PMIP4의 해당 시각에만. 25–130 ka는 Bristol이 답할 때까지 비운다.

### 5. 뒤집힘 순환 보기 (나중, 따로 제안)

표층 입자와 다른 그림이다: 이름 있는 경로를 띠로 그린 모식도(현재)와 위도–깊이 단면의 뒤집힘
흐름함수(과거는 모형). 미리 보기 가지 `preview/ocean-currents`에 시제품이 있다(검토 대상 아님). 과거
단면은 전층 속도나 `Merid_*`가 필요하므로 Bristol의 답 뒤에 따로 계획한다.

## 정할 것 (저장소 주인)

- 과거 지도의 주 자료: HadCM3L 해양 출력(Bristol의 답에 달림), 직접 계산, FOAM 중 무엇인지.
- FOAM을 따로 고를 수 있는 두 번째 자료로 보일지, 비교 표로만 남길지.
- 해수면 온도 층을 해류보다 먼저 낼지, 함께 낼지.
- PhanDA 사전 분포의 CC BY를 그대로 따를지와 어느 계열을 쓸지(#6의 Bristol 문의 1항).

## 확인 방법 (구현 PR)

- `make test`, `npm test`, 새 `tests/currents_check.py`.
- 과거 해류: `?masks=paleodem2018&age=100&currents=flow`에서 지구본·평면 넷을 차례로 본다. 입자가
  그 지도의 해안에서 태어나고 죽는지, 두 정지점 사이에서 대륙과 함께 움직이는지, 시점 줄이 출처를 대는지.
- 100 Ma에서 테티스 통로, 250 Ma에서 판탈라사 게어를 FOAM 그림과 나란히 본다.
- 0 Ma는 P10 그대로인지(`data-flux`, `currents=flow`).
