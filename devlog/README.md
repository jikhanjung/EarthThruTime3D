# devlog 인덱스

수행한 작업의 배경, 구현 판단, 확인 결과와 남은 한계를 기록합니다. 무엇이 관측이고
무엇이 해석이며 무엇이 작업자가 정한 값인지 각 기록에서 구분해 둡니다.

## 파일명 규칙

- 작업 결과: `YYYYMMDD_{nnn}_{title}.md` — 001부터 저장소 내 단조 증가 번호
- 계획 문서: `YYYYMMDD_P{nn}_{title}.md` — P01부터 별도 번호
- title은 영문 snake_case로 작성합니다.

`hanyang3d/devlog/`의 규칙을 따르되 번호는 이 저장소에서 독립적으로 부여합니다.
배포 절차는 [deploy/README.md](../deploy/README.md), 운영 현황은
[docs/operations.md](../docs/operations.md), 뷰어 구조는
[docs/globe-viewer.md](../docs/globe-viewer.md)에 있습니다.

## 지금까지의 줄기

원본 지도 17장을 수집하고(001) 구면에 올린 뒤(002), 그 색에서 육지와 바다를
갈라냈습니다(003). 갈라낸 마스크를 지구본 표면으로 쓸 수 있게 하고(004) 조각마다
이름을 붙였습니다(005). 이름은 지도가 직접 인쇄한 현대 대륙 이름을 픽셀 위치로 옮겨
적어 정했고, 그 덕분에 처음 짐작으로 붙였던 여러 오류를 잡았습니다.

그 다음 시점 사이를 채웠습니다. 거리장을 섞어 해안선을 움직이고(006), 슬라이더 눈금을
설정으로 뺐으며(008), 제자리에서 녹던 대륙을 실제로 이동시켰습니다(009). 이동으로 볼
것과 분할 오차로 볼 것을 가르는 기준은 속도에서 정체성으로 옮겼습니다(010). 인도판이
100만 년당 1.8도까지 갔다는 사실이 속도 상한을 무너뜨렸기 때문입니다.

표시 방식으로는 투영 선택을 더했고(011), 화면이 흔들리지 않게 패널 높이를 고정했으며(007),
휴대폰에서는 지구본과 슬라이더가 먼저 오도록 순서를 바꿨습니다(013).

운영은 dolfinid에 올렸습니다(012). PALEOMAP 이용 조건이 인터넷 게시를 저자 동의가 필요한
용도로 들기 때문에, 원본 지도는 이미지에도 서버에도 올리지 않고 우리가 측정한 육지
거리장만 공개합니다.

## 남은 것

PaleoDEM 시리즈(014)는 015에서 운영 번들에 실렸다. 기후·생물지리 층이 남아 있다.

보간 중간 프레임에는 아직 판이 없습니다. GPlates가 하는 것처럼 회전 모델로 자료를
재구성하려면 조각에 판 번호를 붙이고 회전 모델을 확보해야 합니다. 무엇이 필요한지는
[docs/gplates-reference.md](../docs/gplates-reference.md)에 정리했습니다.

고생대 이전 지도는 팔레트가 달라 분할이 어두운 중심부만 잡습니다(003). 운영에서는
원격지 백업과 복구 리허설이 남아 있습니다(012).
