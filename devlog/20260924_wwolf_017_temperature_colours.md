# wwolf 017 — 기온 색: 지구본과 범례가 같은 색, 그리고 색 아래의 산맥

날짜: 2026-09-24 · 브랜치: feature/temperature-colours · 이전: [wwolf 016](20260924_wwolf_016_rainfall_colours.md)

## 문제

- **범례와 지구본이 다른 색이었다.** 기온 셰이더는 세 정지점(파랑 −30 °C, 옅은 색 0 °C, 빨강 40 °C)을
  `decode()` 한 뒤, 곧 선형 빛에서 섞었다. 범례 막대는 CSS 그라디언트라 인코딩된 sRGB에서 섞는다.
  같은 온도가 두 곳에서 다른 색이었다: 1 °C 간격으로 비교하면 최대 **ΔE2000 13.1**(27 °C; ΔE76 24.7),
  −25~34 °C 전 구간에서 10을 넘었다. 지구본의 색을 범례로 읽을 수 없었다.
- **0~40 °C가 한 줄기였다.** 옅은 색에서 빨강으로 가는 하나의 구간이어서 온대와 열대가 잘 갈리지 않았다.
  사용자가 "기온 색 막대가 직관적이지 않다"고 짚었다.
- **색 아래에서 산맥이 사라졌다.** 지형 음영은 고도 보기에만 있어서, 기온·모형 식생·모형 강수에서는
  히말라야도 안데스도 평평했다.

## 바꾼 것

- `thermal()`을 ColorBrewer **RdYlBu** 열한 정지점으로: −30, −20, −10, −5, 0, 5, 12, 18, 24, 30, 40 °C
  (`#313695` `#4575b4` `#74add1` `#abd9e9` `#e0f3f8` `#ffffbf` `#fee090` `#fdae61` `#f46d43`
  `#d73027` `#a50026`). 영하는 파랑, 0 °C 근처가 옅고, 위로 노랑·주황·빨강. 범위 −30~40 °C와 범례
  눈금(−30, 0, 20, 40 °C)의 위치는 그대로다.
- 정지점을 인코딩된 값에서 섞고 마지막에 한 번 `decode()` 한다. CSS 그라디언트와 같은 방식이라
  지구본의 색이 범례의 색과 같다(구성상 차이 0). `.temp-bar`는 같은 정지점을 같은 위치(%)에 둔다.
- 기온(모드 3)과 모형 기후(모드 4·5)의 육지에 고도 보기의 음영 `shade()`를 곱한다. 평지가 받는 값
  0.749(빛 방향 (−0.6, 0.6, 0.55), 법선 (0, 0, 1): 0.45 + 0.55 × 0.55/1.0112)로 나눠서 평지는 범례의
  색 그대로이고 경사만 밝아지거나 어두워진다(0.55~1.3으로 제한). 바다에는 곱하지 않는다. **지형 음영**
  선택(음영 없음 / 실제 기복 / ×5 / ×20)이 그대로 조절하고, "음영 없음"이면 꺼진다.
- `docs/globe-viewer.md`: 기온 색과 음영 설명.

## 측정

5 °C 떨어진 두 색의 최소 차이(−30~40 °C, 5 °C 간격). 색각 이상은 Machado, Oliveira & Fernandes
2009 행렬(강도 1.0)을 선형 RGB에 적용했다. 기존 색은 지구본이 실제로 그린 색(선형 빛 혼합)이다.

| 색표 | 정상 ΔE2000 | 녹색약 | 적색약 | 정상 ΔE76 | 녹색약 ΔE76 |
|---|---|---|---|---|---|
| 기존 세 정지점 | 4.4 (0→5 °C) | 2.4 | 2.6 | 4.7 | 3.9 |
| RdYlBu(채택) | 6.6 (35→40 °C) | 5.8 | 6.1 | 11.0 | 10.6 |

가장 가까운 쌍이 기존에는 0→5 °C(가장 흔한 온도대)였고, 이제는 가장 드문 35→40 °C다.
계산 스크립트는 저장소에 넣지 않았다(sRGB → CIELAB, CIEDE2000, Machado 행렬; 결과는 위 표).

## 확인

- 화면: 고도 격자 → ☰ 메뉴 **기온**, 투영 **이퀄 어스**. 250 Ma에서 판게아 내륙이 짙은 빨강, 고위도
  바다가 주황이고, 0 Ma에서 남극·그린란드·시베리아가 파랑, 온대가 노랑~주황, 열대가 빨강이다.
  main과 나란히 스크린숏으로 비교했다. 히말라야·안데스·로키의 음영이 기온 색 위에 보인다.
- `make check`, `make test`, `npm test`, `tests/climate-browser.mjs`.
