# jikhanjung 055 — 오버레이 겹침 정리, 번역 파일 검사

날짜: 2026-09-14 · 브랜치: fix/overlay-stacking

## 한 것

- 해수면 곡선 오버레이와 설정 메뉴가 둘 다 제어판 위 왼쪽에 떠서 겹쳤다(052). 메뉴가 열리면 그
  높이를 `--menu-space`로 넘겨 곡선이 메뉴 위로 올라간다. 메뉴 크기는 ResizeObserver로 따라간다.
- 폭 900~1000 px에서 곡선 오버레이와 열린 정보 패널이 가로로 겹쳤다(048). 곡선 폭을
  `min(620px, 100% - 380px)`로 제한해 정보 패널 열(330 px + 여백) 옆에 들어가게 했다.
- `scripts/compile_messages.py`가 msgfmt처럼 같은 msgid가 두 번 나오면 멈춘다. 정렬된 표에 같은
  키가 둘 들어가면 하나가 조용히 버려지기 때문이다. 번역이 비어 있는 항목도 멈춘다. 영어 화면에
  한국어가 섞이는 원인이라서다.

## 확인

- 브라우저 검사: 메뉴와 곡선을 함께 열면 곡선 아래가 메뉴 위쪽보다 위에 있는지, 1000 px 폭에서 곡선
  오른쪽이 정보 패널 왼쪽을 넘지 않는지 본다. 전체 통과.
- 1000 px 캡처에서 곡선·메뉴·정보 패널이 겹치지 않는다.
- 중복 msgid와 빈 msgstr을 넣은 .po로 스크립트가 둘 다 짚어 내고 종료 코드 1로 끝나는 것을 확인했다.
  현재 `django.po`는 통과한다(248개).

## 남은 것

- 짧은 가로 화면에서 열린 메뉴가 지구본 일부를 가린다(052).
