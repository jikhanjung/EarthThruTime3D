# jikhanjung 062 — 시간 범위: 최근 2.5만 년

날짜: 2026-09-15 · 브랜치: feature/deglacial-time-window · 계획: [jikhanjung P01](20260915_jikhanjung_P01_deglacial_time_window.md)

## 한 것

- 고도 격자 시리즈의 타임라인 옆에 "시간 범위" 선택을 더했다. "최근 2.5만 년"(`?window=deglacial`)을
  고르면 슬라이더 전체가 25 ka부터 현재까지 1천 년 간격 26개 시점이 된다.
- 자료(`scripts/build_ice.py`):
  - 저수위 조각 25장(1–25 ka)을 모두 쓴다. 전에는 해수면을 더 내리지 않는 7장(1–5, 20, 25 ka)을 뺐다.
  - 조각마다 `lowers` 를 적는다. 해수면 판정은 `held_levels()` 로 떼어 내 검사한다.
- 서버(`core/globe.py`):
  - 해수면 가정 화면의 `ice_lows` 는 `lowers` 인 조각만 담는다. 이 표시가 없는 옛 기록은 전부 담는다.
  - 창을 고르면 0 Ma 프레임을 조각마다 한 번씩 복제해 보낸다. 각 복제는 자기 나이, 이름(홀로세·
    플라이스토세), `deglacial` `{age_ka, level_m, url}` 를 가진다.
  - 창의 프레임에서는 `ice_sheet`·`ice_lows` 를 뺀다. 눈금은 프레임당 하나이고, 지도 없는 깊은 시점은
    넣지 않는다.
  - 조각이 없으면 선택지를 내지 않는다. 다른 값이나 다른 시리즈에서는 전체 시대를 보낸다.
- 페이지(`static/core/globe.js`, `templates/core/home.html`):
  - 슬라이더, 이전·다음 버튼, 시대 메뉴, 재생은 프레임 구조를 그대로 따른다. 계획에서 걱정한
    `frameStops` 문제는 나이마다 프레임을 따로 보내 없어졌다.
  - 빙하: 조각이 프레임의 저수위 텍스처로 들어간다. 빙붕은 현재 마스크에서 유지되고, 0 ka는 현재
    마스크만 쓴다.
  - 해수면: 조각의 수준이 그대로 적용된다. 해수면 슬라이더와 곡선 체크 상자는 잠기고, 슬라이더는 그 값을
    보여 준다.
  - 색띠: 해수면 색띠는 창의 수준을 저수위 눈금으로 그린다. 기온 색띠는 뺐다.
  - 기온: 창의 프레임은 기온 텍스처와 평균 기온을 갖지 않는다. 21 ka 스크린숏에서 평균 기온이 현재
    값(14.3 °C, 현재 대비 +0.0)으로 나와서 뺐다. Scotese 2021 은 5 Myr 해상도라 최후빙기 추위를 말하지
    못한다.
  - 빙하 안내문은 NADI-1·DATED-1 출처, 현재 지형, 빙하 하중에 의한 지각 침하(GIA) 미반영을 알린다.
  - 영어 번역 10개를 더했다.
- 문서: `docs/globe-viewer.md` "Sea level" 에 조각 규칙과 "Time window" 절.

## 계획에서 달라진 것

- 조각 파일 이름(`ice-low`)과 경로를 그대로 쓰고, 창 전용 목록 `ice_ages` 대신 프레임의 `deglacial`
  하나로 충분했다.
- 1–5 ka 는 해수면이 0 m 로 유지된다. 스택이 현재보다 높게 시작하기 때문이다. 그래도 NADI-1 의
  로렌타이드 잔존 빙하는 조각대로 보인다.

## 확인

- 다시 만든 조각: 25장. 해수면이 이어 받아 유지되는 나이는 1–5, 20, 25 ka 이고, 24 ka 가 −130 m 로
  가장 낮다.
- `make check`, `make test` 52개(창 검사 1개 추가), `tests/ice_check.py` 7개, `npm test` 13개 통과.
- 브라우저 검사 전체 통과. 새 "Time window" 항목의 내용:
  - 26개 시점, 슬라이더 최대 25, 시간 간격 메뉴 없음, 해수면 슬라이더 잠김.
  - 0 ka 에서 `data-ice-age` 0, 해수면 0.
  - 21 ka 에서 `data-ice-age` 21, 해수면 −100 m 보다 낮음, 나이 표시 "21,000".
  - 전체 범위로 돌아가면 시간 간격 메뉴가 돌아오고 슬라이더가 풀린다.
  - 기존 해수면 가정 화면(−130 m → 24 ka 조각)도 그대로 통과했다.

## 남은 것

- 배포 전이다. 자료 묶음에 조각 7장(약 2 MB)이 더해진다.
- 계획의 "나중에": 500년 눈금, 최근 80만 년, 해수면 가정을 곡선에 더하기, NADI-1 최소·최대 윤곽,
  GIA 보정.
