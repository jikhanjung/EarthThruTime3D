# 001 — 프로젝트 초기화 및 Scotese 고지도 수집

날짜: 2026-09-12

## 목표

EarthThruTime3D는 지구 역사를 3차원으로 재구성하는 PaleoBytes 연구 프로젝트다.
첫 목표는 시대별 고지리를 구면 위에서 보여주는 것이며, 이후 지각 운동과 변형,
인도 아대륙 충돌·히말라야 형성 같은 지역 사례, 장기적으로 맨틀 대류까지 확장한다.
1만 년 tick은 탐색·보간 간격으로 다루고 실제 자료의 시간 해상도나 물리 정확도와 구분한다.

## 웹 프로젝트 초기화

- Django 5.2.17과 의존성을 고정하고 저장소 전용 `.venv`를 구성했다.
- `config/settings/`에 공통·개발·운영 설정을 분리했다. 운영은 명시적인 비밀키,
  호스트 목록, 영속 DB 경로를 요구하며 HTTPS와 보안 쿠키를 기본 적용한다.
- 로컬 SQLite 기본 마이그레이션을 적용했다. 데이터와 비밀 설정은 Git에서 제외한다.
- 홈·소개·개인정보·문의 화면, 공통 PaleoBytes 푸터와 단일 버전 정의를 추가했다.
- 관리자 접근은 활성 staff superuser로 제한한다.
- `/healthz`는 DB와 마이그레이션 기록을 확인하고 `ok`, `unhealthy`, `degraded`를 구분한다.
- `.guides -> ../devdocs/guides` 상대 링크를 생성하고 Git에서 제외했다.
  `AGENTS.md`와 `CLAUDE.md`에서 비공개 원문을 참조한다.
- 운영 배포·백업 자동화는 아직 구현하지 않았으며 적용할 계약은 `docs/operations.md`에 기록했다.

## 초기 고지도 자료

Scotese.com의 Earth History 목록에서 미래 예측 3개를 제외하고 과거부터 현재까지
17장의 원본 JPEG를 수집했다. 범위는 650 Ma부터 현재까지이며 총 2,147,526 bytes다.
실제 크기는 720 × 455/456/467 px다. 원본 이미지 17개, 시대별 HTML 17개,
목록·이용 안내 HTML 2개, 합계 36개 파일을 로컬 데이터 폴더에 저장했다.

- 원본: `data/sources/scotese/images/`
- 페이지 스냅샷: `data/sources/scotese/pages/`
- Git에 포함할 출처 목록: `sources/scotese-earth-history.json`
- 자료 안내: `sources/README.md`
- 재다운로드·검증: `scripts/fetch_scotese.py`

출처 URL, 수집 시각, SHA-256, 파일 크기, 이미지 크기, 이미지 표기 연대와 불일치 메모를
기록했다. 이미지는 17장 모두 직접 열어 표기를 확인했으며 가공하지 않았다.

### 발견한 연대 불일치

| 항목 | 파일명 또는 페이지 | 실제 이미지 표기 | 처리 |
| --- | --- | --- | --- |
| 전기 석탄기 | `342.jpg` | 356 Ma | 356,000,000년으로 기록 |
| 중기 에오세 | `050.jpg` | 50.2 Ma | 50,200,000년으로 기록 |
| 중기 마이오세 | 페이지 본문 20 Ma | 14 Ma | 이미지 기준 14,000,000년으로 기록 |

최후빙기극대기의 18,000년 표기는 원본의 표기를 보존했다. 원본 지질시대 명칭을 현대
층서표에 맞춰 자동 수정하지 않았다. 파일명만으로 연대를 추출하면 잘못된 보간 기준점이
만들어질 수 있다는 점을 확인했다.

### 접근 및 이용 조건

`scotese.com`과 `www.scotese.com`의 HTTPS 인증서가 호스트명과 일치하지 않아 공개
HTTP 경로로 받았다. 체크섬은 수집한 바이트의 동일성을 확인하며 서버의 진위를 보증하지 않는다.

사이트의 이용 안내는 적절한 출처를 표기한 개인·교육·연구·과학 출판 용도를 허용하고
상업 용도 등에 대해서는 저자의 서면 동의를 요구한다. 로컬 연구 원본은 기존 `data/`
제외 규칙을 유지하며, 웹에서 제공하지 않는다. 저장소에는 출처 목록과 도구만 포함한다.
재다운로드 도구는 기존 파일을 덮어쓰지 않으며 새 파일도 체크섬 검증 후 반영한다.

## 검증

- Django 기본 마이그레이션 적용 완료.
- `make check`: 시스템 오류 없음, 누락 마이그레이션 없음.
- `make test`: 공개 화면·상태 점검·DB 오류 응답·관리자 권한 테스트 4개 통과.
- `collectstatic --noinput`: 정적 파일 129개 수집 완료.
- 운영 `check --deploy`: HSTS 하위 도메인 및 preload 경고 2개. 도메인 확정 전 기본 off를 유지한다.
- 소스 검증: 지도 17장 포함 36개 자산의 파일 크기와 SHA-256 일치.
