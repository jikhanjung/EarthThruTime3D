# P07 — CRUST 2.0으로 현재 지구의 지각 두께 표시

날짜: 2026-09-16 · 작성자: jikhanjung · 상태: 색상 지도·구면 기준 지각층 구현, 물리적 모호면 보류

구현 중 확인: 패키지 범례로 km 단위는 확인했으나 물·얼음 포함과 고도 기준은 확정하지
못했다. 따라서 3단계의 실제 암석 윗면–모호면 대신 **표시 지표 아래 두께 등가 구면층**을
구현한다. 자료값과 지표 고도를 결합한 물리적 깊이라고 해석하지 않으며 화면에 명시한다.
현재 범위는 색상 지도와 이 설명용 단면까지이고, 물리적 모호면은 기준 확인 후 별도 작업이다.

## 목적과 범위

현재 지구에서 해양과 대륙의 지각 두께 차이를 색상과 절개면으로 보여준다.
기존 지표·맨틀 보기와 연결하되, 지각 두께와 지표 고도는 별도 물리량으로 다룬다.
첫 구현은 **0 Ma의 현재 지구**에 한정한다. 과거 두께 복원과 변형 계산은
[P03](20260915_jikhanjung_P03_crustal_deformation_mantle_coupling.md)의 별도 후속 작업이다.

## 확인한 입력 자료

- [EarthByte GPlates 2.3 Crustal_Thickness.zip](https://www.earthbyte.org/webdav/ftp/earthbyte/GPlates/GPlates2.3_GeoData/Rasters/Crustal_Thickness.zip)
- 2026-09-16 HTTP 200으로 전체 다운로드: **83,928,224 bytes**. ZIP CRC 검사 통과.
- SHA-256: `0375cf41ea79d007ffe3452825131de69a438ff1ef1101c9faca5eb3c1299933`.
- ZIP 안에 NetCDF, PNG, 범례 PNG, GPML, `License.txt`가 있다.
- NetCDF를 실제로 열어 longitude/latitude와 수치 변수 `z`를 읽었다.
  크기 10,801 × 5,401, 값 범위 약 0.3548–76.7097이다.
- NetCDF 이력은 `grdsample -Rd -I2m Crustal_Thickness.grd -fg -GCrustal_Thickness.nc`.
  **2분각 배포 격자는 2° CRUST 2.0의 재표본화 결과이며 새로운 공간 정확도가 아니다.**
- 패키지 `License.txt`에는 CC BY 4.0이 명시되어 있다. 해당 배포본의 라이선스와
  원저자 인용을 함께 보존하며, 다른 CRUST 배포본 전체의 조건으로 일반화하지 않는다.
- 다운로드 검증 파일은 `/tmp/earthbyte-access-check/Crustal_Thickness.zip`에 있다.
  임시 경로는 영구 입력 저장소가 아니므로 구현 단계에서 기존 원본 보관 체계에 등록한다.
- UCSD CRUST 1.0 원본과 IRIS 대체 파일은 이 환경에서 HTTP 403이었다.
  이번 구현은 실제 확보한 CRUST 2.0 배포본으로 고정한다.

## 현재 코드와 연결점

- `static/core/globe.js`: 지표 셰이더, 고도 강조, 좌표 변환, mantle bridge.
- `static/core/mantle-scene.js`: 지표 투명도와 원형 절개, 맨틀 메쉬·핵 참고 구.
  현재 절개는 셰이더 discard이며, 잘린 경계에 지각 두께를 나타내는 벽은 없다.
- `static/core/mantle-overlay.js`: DOM 제어와 연대별 맨틀 자료 준비.
- CRUST 자료 제어와 메쉬는 별도 모듈로 분리한다. 맨틀 컨트롤러가 지각 데이터를
  소유하지 않도록 하고, 절개 위치·반경과 표시 상태만 공통 인터페이스로 전달한다.
- 현재 맨틀의 slabs/piles는 추출된 표면이다. 새 지각의 아래쪽 경계가 OPT1 맨틀과
  물리적으로 결합되었다고 설명하지 않는다.

## 1단계 — 데이터 등록과 의미 검증

1. 다운로드 URL, 해시, 바이트 수, 원저자 인용, 패키지 라이선스, 처리 이력을
   `sources/` manifest와 데이터 출처 문서에 등록한다. 외부 사이트는 빌드 입력이며
   사용자 브라우저가 직접 접근하는 경로로 사용하지 않는다.
2. **단위와 두께 기준을 먼저 확인한다.** NetCDF `z`에는 units 속성이 없다.
   패키지 범례·EarthByte 설명·원모델 문서를 대조해 km 여부 및 물/얼음/퇴적층 포함
   기준을 확정한다. 수치 범위만으로 단위를 추측하지 않는다.
3. 지각 두께와 해수면 기준 모호면 깊이를 혼동하지 않는다. 해저에서는 수심을
   지각 두께에 더해 표시하지 않으며, 얼음도 암석 지각으로 취급하지 않는다.
   기준이 확정되기 전에는 물리적 모호면 높이를 만드는 단계로 넘어가지 않는다.
4. 첫 배포 격자는 **1°**를 제안한다. 이는 이미 재표본화된 자료의 표시용 축소본이다.
   원래 2° 셀 값을 복구했다고 주장하지 않는다. 해양–대륙 경계에서 평균으로 두께가
   섞이는 정도를 비교하고 처리 방법을 고정한다. 결측은 0 두께와 구별한다.
5. 두께는 0.01 km 단위 uint16과 결측 코드로 저장하는 안을 우선 검토한다.
   360 × 180이면 순수 수치 배열은 129,600 bytes이며, 10 m 저장 간격은 정확도가 아니다.
   메타데이터·압축·메쉬를 포함한 실제 전송량은 생성 후 측정한다.
6. 원본은 자료 보관 영역에 유지하고 웹 배포에는 파생 파일만 포함한다.
   기대 해시를 가진 재현 가능한 변환 명령과 오프라인 검증을 제공한다.

## 2단계 — 지각 두께 색상 지도

- 별도 `지각 두께 / Crustal thickness` 옵션을 추가한다. 기본 Off, 현재(0 Ma)에서 사용.
- 색상은 두께에 따른 연속 팔레트와 km 범례를 사용한다. 기온 등 기존 색상 레이어와
  동시에 색을 덮어 의미가 섞이지 않도록 기존 표면 모드 선택 구조에 통합한다.
- 클릭한 위치에 두께, 자료명, 원모델 해상도를 표시한다. 표시값은 1 km 정도로 반올림하고
  원자료의 보간값임을 설명한다. 숫자의 자리 수로 정밀도를 과장하지 않는다.
- 2D 투영에서도 색상 지도는 지원하고, 지각 단면·입체 두께 제어는 지구본에서만 제공한다.
- 맨틀을 켜지 않아도 사용할 수 있다. 로딩 실패 시 지표는 유지하고 재시도 안내를 표시한다.

## 3단계 — 두께가 있는 지각층과 절개면

- 기존 지표를 윗면으로 활용하고, 지각 아랫면과 절개 경계의 옆면을 추가한다.
  전 지구 지표를 중복 생성해 깜빡임이나 깊이 충돌을 만들지 않는다.
- 기존 원형 cutaway의 중심·반경과 동일한 경계에서 옆면을 만든다. 원형 절개의 이동,
  날짜변경선·극점 통과에서도 윗면과 아랫면 사이가 벌어지지 않도록 한다.
- 물리 좌표의 아랫면은 확인된 암석 윗면에서 두께를 빼서 계산한다. 기존 PaleoDEM 지표와
  CRUST가 사용한 지형의 차이는 남을 수 있으므로 결합 단면의 근사임을 표시한다.
- 실제 비율 **1×를 기본**으로 제공하고 선택적으로 두께 강조 **5×**를 제공한다.
  강조 상태는 항상 표시한다. 지표 고도 강조와 지각 두께 강조를 구분하며, 강조한 단면에서
  읽는 km 수치는 화면상의 거리 대신 원자료 값으로 유지한다.
- 불투명한 아랫면 때문에 맨틀이 전부 가려지지 않도록 절개와 투명도 정책을 함께 적용한다.
  5×에서 맨틀 메쉬와 겹칠 수 있으며, 이 모드는 설명용 표시라는 점을 명시한다.
- 기존 맨틀 옵션의 기본값(절개 Off, 지표 opacity 70%)은 유지한다.

## 시간 전환과 상태

- 0 Ma를 벗어나면 CRUST 레이어를 숨기고 `현재 지구 자료 — 이 연대에는 제공되지 않음`을
  표시한다. 현재 두께 지도를 과거 대륙 위에 그대로 얹지 않는다. 최근 빙기 창도 같은 규칙이다.
- 사용자가 선택한 On 상태와 강조 배율은 기억하고 0 Ma 복귀 시 복원한다.
- 연대 전환 중 지표·맨틀은 기존처럼 유지한다. 새 연대가 실제 적용되는 시점에 CRUST의
  가시성도 함께 바꿔 화면의 연대와 데이터가 어긋나지 않게 한다.
- 이미 받은 현재 지각 파일은 캐시하고, Younger/Older마다 다시 다운로드하거나
  전체 지구를 지웠다가 만들지 않는다. 취소된 요청은 뒤늦게 표시 상태를 덮지 못하게 한다.

## 검증과 완료 기준

- 데이터: ZIP/파생 파일 해시, 차원, 좌표 방향, 결측, 단위·기준, 원자료 표본 대조.
  날짜변경선 이음부와 북/남반구 뒤집힘을 자동 검사한다.
- 공간: 대양·대륙·티베트 등 대표 위치를 패키지 지도/범례와 비교한다.
  1× 두께에서 윗면–아랫면 거리와 원자료 값이 수치상 일치하는지 검사한다.
- 화면: 지표 확대·고도 강조, cutaway 이동, 맨틀 투명도, 색상 모드 전환,
  2D/3D, 한영 전환, 모바일, Chrome·Firefox를 확인한다.
- 비동기: 빠른 0→20→0 Ma 전환, 다운로드 실패·취소에서 지구가 사라지지 않고
  과거 화면에 현재 두께가 남지 않는지 검사한다. 반복 토글의 GPU 자원 누수도 점검한다.
- 행동 변경에 `make check`, `make test`를 실행한다. 실제 전송량과 표시 성능을 기록한다.
- 두께 지도와 단면이 모두 동작해야 이 계획의 지각 표시 구현을 완료로 처리한다.
  단계별 PR은 가능하지만 색상 지도만으로 전체 완료라고 기록하지 않는다.
- 구현 시 브랜치 생성과 각 PR 작성 전 main/open PR/issues를 다시 확인한다.
  출처·라이선스 표시, devlog, 검증 결과를 포함해 리뷰 가능한 변경으로 정리한다.
