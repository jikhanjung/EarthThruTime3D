# CRUST 2.0 현재 지각 표시

날짜: 2026-09-16 · 브랜치: `feature/crust2-visualization`

## 자료 접근 확인과 판단

- EarthByte의 CRUST 2.0 ZIP 전체 83,928,224 bytes를 받아 CRC와 NetCDF 읽기를 확인했다.
  해시·출처·라이선스 근거를 `sources/crust/crust2.json`에 고정했다.
- UCSD CRUST 1.0과 IRIS 대체 파일은 이 환경에서 HTTP 403이었다. 이번 구현은 실제
  확보한 EarthByte 배포본으로 진행했다. 이를 CRUST 1.0 서버 전체 중단으로 단정하지 않는다.
- 원본 PNG 범례의 `Thickness (km)`로 단위는 확인했다. 그러나 NetCDF에 물·얼음 포함과
  기준 고도가 없으므로 실제 모호면 깊이를 계산하지 않는다. P07을 수정해 표시 지표 아래
  두께 등가 구면층을 구현하고, 물리적 모호면은 기준 확인 후 후속 작업으로 남겼다.
- 원모델은 2°. 배포 NetCDF의 2분각 격자나 이번 1° 격자는 추가 정확도가 아니다.

## 구현

- `scripts/build_crust.py`: 고정 ZIP 검증, 1° 셀 중심 표본, uint16 0.01 km 저장,
  결측 65535, 파생 파일 해시·gzip·catalogue 생성. 검증된 원본은 `data/raw/crust`에 보관.
- 단일 수치 배열 129,600 bytes, gzip 전송 65,829 bytes. 배포 묶음에는 원본 없이
  catalogue·binary·gzip 3개, 총 196,120 bytes가 추가된다.
- `core/crust.py`: 선택 자료의 실패 격리, 안전한 파일 경로, 해시·길이 검증, gzip/ETag 제공.
- `static/core/crust.js`: 지각 컨트롤러, 색상 지도, km 읽기, 구면 지각층과 원형 절개의 옆면.
  지표는 기존 메쉬를 사용하며 아랫면과 옆면만 추가한다. 1× 기본, 5× 선택.
- 맨틀이 없어도 지각을 켤 수 있다. 맨틀 절개가 켜지면 동일한 중심과 반경을 사용한다.
  지각 단독 절개에도 격자선·지명 숨김을 적용했다. 배율은 지구 위에도 표시한다.
- 평면 투영은 색상 지도만 지원한다. 기온·표면 모드를 직접 선택하면 지각 색상을 해제한다.
- 0 Ma에서만 표시한다. 과거로 전환하면 옵션을 기억하며 숨기고 현재 복귀 시 복원한다.
  지각 다운로드는 지표 로딩을 막지 않는다. 늦은 응답은 적용된 연대와 옵션을 다시 확인한다.
- 자료는 페이지 내 재사용하며 절개 이동 시 옆면 기하만 갱신한다. 전체 지구를 지웠다가
  다시 생성하지 않는다. 지각 셰이더 모듈도 버전 import map에 포함했다.
- 한영 UI·About·LICENSE-DATA·출처·[구현 문서](../docs/crust.md)를 추가했다.
  런타임 packer와 이미지 smoke 검사에 경량 파생 자료를 연결했다. DB나 운영 비밀은 변경 없다.

## 검증

- `make check`: Django 설정·번역·migration 검사 통과.
- `make test`: Django 83개 테스트 통과. 파일 변조·비정상 manifest·gzip/ETag·안전한 배포 포함.
- `npm test`: JS 7개 테스트 파일 통과. 지각 격자의 결측/0/남북/날짜변경선,
  실제 비율 거리, 극점·날짜변경선의 절개 원 닫힘 검사 포함.
- Chromium: lazy load, 재사용, 실패/재시도, 0↔20/40 Ma, 두 평면 투영, 극점 절개,
  맨틀 절개 공유, 위치 클릭, 모바일 화면 및 셰이더 오류 없음 확인.
- Firefox 146.0.1 + Xvfb: 지각 색상·단면·5×·20→0 Ma 통과. 기존 -60 m 하천/빙하와
  20 ka 빙기 검사도 통과. 콘솔·네트워크 오류 없음.
- 이 환경의 headless Firefox는 WebGL2 생성에 실패해 기존 Xvfb 실행 방식으로 검증했다.
- 런타임 지각 3개 파일을 별도 임시 묶음으로 복사해 해시 및 gzip 원문 일치를 확인했다.
- 화면: `test-results/crust-cutaway.png`, `crust-mantle.png`, `crust-mobile.png`,
  `firefox-crust.png` (gitignored).

## 남은 한계

표시 지표의 기복과 자료의 두께를 합친 설명용 형상이다. 해저 기반암 고도, 물·얼음 포함
기준을 확정한 실제 모호면, 과거 지각 두께, 충돌·변형 계산은 구현하지 않았다.
운영 릴리스·배포는 이 기록에 포함하지 않는다.
