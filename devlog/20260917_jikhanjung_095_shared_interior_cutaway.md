# 지각·맨틀 공통 패널과 위도·경도 절개

## 요청과 변경

CRUST 2.0과 맨틀 중첩을 함께 다룰 수 있도록 지구 내부 패널을 통합했다.
사용자가 공통 패널·절개를 선택했고, 이어 원형 대신 위도·경도 범위를 요청했다.

- 패널 상단에서 지각과 맨틀을 독립적으로 켠다. 공통 지표 절개의 남·북 위도와
  서·동 경도를 두 레이어가 공유하며, 한 레이어를 꺼도 범위 선택은 유지된다.
- 남쪽 위도가 북쪽 이상이 되지 않도록 입력을 제한한다. 서쪽 경도가 동쪽보다 크면
  날짜변경선을 넘는다. −180°→180°는 전 경도, 같은 경도는 절개 없음이다.
- 지각 벽은 위선·경선을 따라 만들며, 전 경도 띠에는 날짜변경선의 가짜 벽을 만들지 않는다.
  경계의 0.5° 샘플 간격은 화면 기하의 간격이며 CRUST 2.0 해상도·정확도를 뜻하지 않는다.
- India–Asia는 35°E–125°E, 35°S–55°N의 위치 프리셋이다. 범위만 재설정하며,
  절개 토글이나 고정 A–A′ 과학 단면을 변경하지 않는다. A–A′ 설정은 별도 펼침 영역에 둔다.
- 맨틀을 켤 때 항상 80 Ma로 가던 동작을 바꿨다. 현재 연대에 가장 가까운 원본 시점을
  선택하고, 0 Ma에서는 지각과 카메라를 유지한다. 20 Ma 등 과거에는 현재 지각을 숨기며
  0 Ma로 돌아오면 캐시와 선택 상태를 복원한다.
- 절개 기본값 Off와 맨틀 지표 불투명도 70%는 유지한다. 평면 투영에서는 공통 절개를
  비활성화하고 지각 색상만 표시한다.

## 구현과 과학적 범위

`interior-controls.js`는 공통 입력·프리셋·카메라 이동 요청을 관리한다.
`interior-cutaway.js`는 범위 판정·경계 샘플·공통 shader 함수를 제공한다.
지표·기후·빙하·선·지명·지각 벽이 같은 절개 영역을 사용하며, 맨틀 내부 구조는 유지한다.
두 모듈을 버전 import map에 추가했다. 한영 문구와 관련 브라우저 검사를 갱신했다.

CRUST 2.0은 여전히 현재 지각 두께의 설명용 구면층이다. 과거 지각 재구성이나
실제 모호면·맨틀과의 물리 결합 계산을 도입하지 않았다. 원본 자료·회전 정합·맨틀 메시도 동일하다.

## 검증

- `make check`, Django 83개, JS 8개 파일 검사 통과.
- 범위 단위 검사: 일반 영역, 날짜변경선 양쪽, 전 경도·빈 범위, 위선/경선 경계,
  극점과 전 경도 띠에서 불필요한 벽 제외.
- Chromium 지각 검사: 자료 로딩·재시도·캐시·연대 제한·평면 투영·범위 절개·맨틀 공유·모바일.
- Chromium 맨틀 검사: 다섯 연대, A–A′ 팝업 시간 공유, 취소·실패·재시도·투영 복원·한영·모바일 통과.
- Younger/Older 전환 검사: 로딩 중 동일한 지구 화면을 유지하고 준비된 지표·맨틀을 함께 교체함을 확인.
- Firefox 146.0.1: 새 지각 절개·5×·20→0 Ma, 하천·저수위·빙기 검사 통과.
- 화면 기록은 gitignored `test-results/`에 저장했다. 새 기본 절개와 날짜변경선·전 경도 띠를 검사했다.
