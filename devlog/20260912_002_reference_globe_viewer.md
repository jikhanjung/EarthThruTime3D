# 002 — Scotese 고지도 지구본 뷰어

날짜: 2026-09-12 · 버전: 0.2.0

## 구현

홈 화면에 Three.js 0.186.0 지구본을 추가했다. 로컬 Scotese 지도 17장을 구면에
배치하며, 드래그·휠·핀치, 키보드 회전·확대, 자동 회전, 참고 격자, 시점 초기화,
시대 선택·슬라이더·순서 재생을 지원한다. 원본 미리보기와 출처도 함께 표시한다.
라이브러리와 MIT 라이선스를 저장소에 포함해 런타임 CDN 의존성을 없앴다.

## 구면 변환

지도별 타원 영역의 픽셀 경계를 직접 추정하고 Mollweide 투영을 가정했다.
브라우저에서 정거원통형 캔버스의 각 경위도에 대응하는 원본 픽셀을 bilinear
방식으로 샘플링해 1024 × 512 텍스처를 만든다. 원본 파일은 수정하지 않는다.
구면 가장자리에는 시선 방향에 따른 음영만 적용하고, 색으로 높이를 추정하지 않는다.

이것은 근사적인 지도 시각화다. 원본의 정확한 투영·중앙경선은 미확정이며,
지도 내부 주석·경계·적도선과 극지/접합부 왜곡이 남는다. 지질시대 표기는 원본을
따른다. 시대 재생은 키프레임 전환이며 지각 운동의 보간이나 물리 시뮬레이션이 아니다.

## 데이터 제공 범위

원본은 계속 `data/`에 보관한다. Django는 목록에 등록된 지도 ID의 JPEG만 제공한다.
개발 설정에서는 뷰어를 켜고, 운영에서는 `SCOTESE_VIEWER_ENABLED=false`를 기본으로 한다.
페이지 스냅샷·DB 등 임의 파일을 노출하는 경로는 만들지 않았다.

## 검증과 수정

- Django 검사 및 테스트 7개 통과.
- JS 투영 테스트: 적도·극점·날짜변경선, 반구 방향, 타원 범위와 이미지 축 방향 확인.
- Chromium에서 17개 지도 모두 표시, 키보드/마우스 조작, 재생, 빠른 시대 전환 확인.
- 요청 순번으로 늦게 끝난 이미지 로딩이 최신 시대를 덮어쓰지 않게 했다.
- 원본 404를 강제로 발생시킨 뒤 재시도로 복구되는 것 확인.
- 모바일 가로 넘침 없음. 초기 렌더에서 구가 좌우로 잘리는 것을 발견해 화면 비율에
  따라 카메라 시야각을 조절했다.
- 데스크톱·모바일 캡처를 `data/screenshots/`에 저장하고 직접 확인했다.

변환 설명과 실행 방법은 `docs/globe-viewer.md`, 브라우저 검증은
`npm run test:browser`에 정리했다.
