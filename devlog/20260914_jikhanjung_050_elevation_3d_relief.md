# jikhanjung 050 — 확대하면 고도 격자를 3D로

날짜: 2026-09-14 · 브랜치: feature/elevation-3d-relief

## 한 것

고도 격자 시리즈를 지구본으로 볼 때, 일정 이상 확대하면 땅이 높이만큼 솟고 시점이 지평선 쪽으로
기울어 입체로 보인다.

- 높이 올리기: 정점 셰이더가 조각 셰이더와 같은 텍스처에서 높이를 읽어, 해수면 위 높이만큼
  구의 반지름을 키운다.
  - 지도 사이에서는 색과 같은 이동장(`travel`)과 섞기(`blend`)를 따르므로, 움직이는 대륙의 산도
    함께 움직인다.
  - 두 셰이더가 같은 GLSL(`TRAVEL_GLSL`, `METRES_GLSL`)을 나눠 쓴다.
  - 바다는 해수면에 평평하게 둔다. 해수면 조절값(`seaLevel`)을 빼고 높이를 재므로, 해수면을
    낮추면 드러난 대륙붕도 솟는다.
- 과장: 실제 비율이면 에베레스트도 지구 반지름의 0.14%라 보이지 않는다.
  - 25배로 과장한다(`RELIEF_SCALE`). 10배로는 티베트고원과 안데스가 지평선 위로 거의 드러나지
    않았다.
  - 설명 패널의 입체 지형 안내가 과장 배율을 밝혀, 실제 비율로 오해하지 않게 한다.
- 기울이기: 원래 카메라는 늘 구의 중심을 내려다봐서 솟은 땅이 옆에서 보이지 않는다.
  - 그리는 카메라만 발밑 지면점을 축으로 최대 50°(`RELIEF_TILT`) 기울인다.
  - 조작(OrbitControls)은 기울이지 않은 카메라를 그대로 움직여, 기울기가 조작에 되먹임되지 않는다.
- 언제: 확대 계수(기본 1)가 0.3보다 작아지면 켜지기 시작해 0.12에서 다 켜진다. 높이와 기울기가
  함께 서서히 바뀐다.
  - 켜진 동안만 구를 512×256 분할로 바꾸고, 꺼지면 96×64로 돌린다.
  - 평면 지도, 대륙 마스크 화면, 높이가 없는 540 Ma 이전 PaleoAtlas 구간, 지도 없는 시대에서는
    켜지지 않는다.
- 도구 막대의 "3D 지형" 버튼으로 끄고 켠다. 기본은 켬이다. 지구본 요소의 `data-relief`가 현재
  세기(0–1)를 알린다.

## 확인

- Django:
  - 고도 격자 페이지에 버튼과 안내가 있는지 본다.
  - 높이가 없는 PaleoAtlas 기본 페이지에는 버튼이 없는지 본다.
- 브라우저: `+`로 확대하면 `data-relief`가 0.9를 넘고 안내가 보이는지 본다. 버튼으로 끄면 0으로
  돌아가고, 다시 켜면 돌아오고, 시점 초기화로 0이 되는지도 본다.
- 캡처: 히말라야와 안데스로 돌려 확대했을 때 고원과 산맥이 지평선 위로 솟는다. 셰이더 오류와
  페이지 오류는 없었다.
- main에 #16–#21을 합친 뒤 그 위로 옮겼다.
  - `home.html`의 안내 줄과 브라우저 검사가 #19·#20과 같은 자리에 들어가 겹쳤고, 둘 다 살렸다.
  - #20·#21 뒤에도 `seaLevel` 유니폼과 `mode` 값의 뜻은 그대로다.

## 남은 것

- 판 경계선과 화석 해안선은 지면 높이를 따르지 않아, 솟은 산 아래로 가려질 수 있다.
- 6분 격자로 텍스처를 다시 만들었으므로(wwolf 001), 배포 텍스처가 바뀌면 가까이서의 계단은
  줄어든다. 안내 문구는 해상도를 적지 않고 "격자 칸이 보일 수 있다"고만 한다.
- 기울기는 화면 아래쪽에서 위로만 기운다. 방향을 사용자가 바꾸는 조작은 없다.
