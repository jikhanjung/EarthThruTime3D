# jikhanjung 076 — 연대 전환 중 지각·맨틀 화면 유지

날짜: 2026-09-16 · 대상: v0.13.0 추가 요청

## 문제와 변경

반투명 지각으로 맨틀을 보는 중 Younger/Older를 누르면 지구가 지워졌다 다시 나타났다.
`selectStop`이 지표를 숨겼고, 맨틀의 준비 여부가 표시 여부까지 결정해 로딩 때 이전 메시도 숨겼다.

- 로딩 준비 상태와 기존 화면의 표시 상태를 분리했다. 현재 지각·맨틀·핵·단면선,
  반투명도·절개 설정을 유지한다.
- 다음 지표·빙하·하천·선 자료와 맨틀 메시를 병렬로 준비한다. 모두 준비된 뒤 지표와 맨틀을
  같은 렌더 프레임에서 교체하며, 교체 시점에만 이전 GPU 메시를 해제한다.
- 지구 위의 표시 연대는 기존 화면의 연대를 유지하고 로딩 안내에 요청 시점을 표시한다.
- 취소·빠른 연속 입력은 요청 식별자와 AbortController로 늦은 결과를 버린다.
  실제 실패 시 자료 없음·오류·재시도 처리는 유지한다.
- 연대 사이 새 형상을 과학적으로 계산하거나 맨틀 메시를 보간하는 변경은 아니다.

## 검증

- `make check`, Django 73개, JS 5개 파일 통과.
- 지표와 맨틀 응답을 따로 지연시키는 Younger/Older 브라우저 검사 추가.
  기존 캔버스가 로딩 동안 유지되고 준비 후 형상과 연대가 함께 바뀌는지 확인한다.
- `mantle-transition-browser.mjs` 통과: Younger·Older 양방향 모두 지구 영역의 픽셀이
  로딩 중 그대로 유지됐고 지표만 먼저 도착해도 바뀌지 않았다. 준비 후 지표·맨틀·연대가 함께 바뀌었다.
  화면 비교는 HTML 로딩 안내를 제외하고 수행했다.
- 기존 맨틀 중첩·전체 지구본 회귀 검증은 릴리스 기록 075에 이어 기록한다.
