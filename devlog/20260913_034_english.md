# 034 — KO|EN 언어 전환

날짜: 2026-09-13

## 한 것

- 헤더 오른쪽 끝에 KO | EN 전환을 두었다. 코드는 나라 코드(KR)가 아니라 언어 코드(ko)를 쓴다.
  누르면 `/lang/<코드>/`가 언어 쿠키를 놓고 보던 주소로 돌려보낸다. 돌아갈 주소는 `core.access.safe_next`로
  내부 경로만 받는다. 기본은 한국어이고, 쿠키가 없으면 Django의 `LocaleMiddleware`가 브라우저 언어를 본다.
- Django의 i18n을 썼다. 원문은 한국어이고 영어는 `locale/en/LC_MESSAGES/django.po`에 176개 항목이다.
  - 템플릿: 모든 문장을 `{% trans %}`, `{% blocktrans %}`로 감쌌다. 판 모델 수처럼 단수·복수가 갈리는 문장은
    복수형으로 두었다.
  - Python: 2002 지도 라벨, 시대 이름 표, 마스크 원본 이름, 시간 간격 라벨을 요청 언어로 번역한다.
  - 뷰어 스크립트: 화면에 쓰는 문장 44개를 서버가 번역해 `globe-strings`로 넘기고, 스크립트는 `{자리}`를
    채워 쓴다. 스크립트 자체에는 한국어가 남지 않는다.
  - 대륙 이름: 조각 보고서의 `name_en`을 영어일 때 쓴다. 2016 지도의 판 무리 표와 2002 지도의 라벨 표
    모두 영어 이름이 있다.
- 컴파일: 이 호스트에도 이미지에도 `msgfmt`가 없어서 `scripts/compile_messages.py`가 `.po`를 `.mo`로
  직접 만든다. `make check`, `make run`, Docker 빌드가 먼저 돌린다. `.mo`는 커밋하지 않는다.
- 함께 고친 것:
  - 격자를 기본으로 켰다.
  - 슬라이더 패널과 바닥글 사이 여백을 줄였다. 본문 아래 32 px과 바닥글 위 28 px이 겹쳐 있었는데, 6 px으로
    줄였다.

## 확인

- Django 37개 통과. 영어 쿠키로 첫 페이지, 2002 비교 페이지, 소개, 개인정보, 문의를 열어 한글이 한 글자도
  남지 않는지 본다. 이 검사가 `.po`에서 빠진 문장을 잡는다. 대륙 이름에 Africa가 있는지, 기본이 한국어인지,
  모르는 언어 코드가 404인지, 바깥 주소로 돌려보내지 않는지도 본다.
- 브라우저 검사 통과. EN을 누르면 같은 화면에서 영어로 바뀌고 대륙 이름이 영어가 되며 본문에 한글이 없는지,
  750 Ma가 Tonian인지, KO로 돌아오는지 본다. 격자가 켜진 채 시작하는지도 본다.

## 배포

v0.8.8로 배포했다. 처음 빌드는 두 번 실패했다. `.dockerignore`가 `scripts/`와 `locale/`을 빼고 있어서 컴파일러와
번역이 이미지에 없었고, 고친 뒤에는 Dockerfile에서 환경 변수를 첫 명령에만 붙여 `collectstatic`이 SECRET_KEY
없이 돌았다. 번역 컴파일을 앞으로 빼고 환경 변수를 `collectstatic`에 붙여 해결했다.

## 남은 것

- 영어 문장은 내가 옮긴 것이라 다듬을 곳이 있을 수 있다. `.po` 파일만 고치면 된다.
- 판 모델의 인용과 기준틀 설명, 지도의 영문 제목은 원문이 영어라 그대로 나온다.
