# jikhanjung 074 — 맨틀 통합 리뷰 후속 수정

날짜: 2026-09-16 · 계획: [P06](20260915_jikhanjung_P06_mantle_integration_review_fixes.md)
브랜치: `fix/mantle-review` · 기준: #38·#39 병합 후 main `eea15d4`

## 변경

- 카탈로그·설정 파싱/스키마 오류는 로그를 남기고 선택 기능만 끈다. 홈·맨틀·단면 페이지는
  자료 준비 안 됨 상태로 응답하며, 자산 경로는 잘못된 자료를 404로 거부한다.
- `core/experiment_assets.py`로 검증·gzip·ETag를 모았다. 파일은 최초 검증 후 스트리밍하며,
  경로·장치·inode·크기·mtime_ns·ctime_ns·기대 해시로 결과를 최대 256개 캐시한다.
  같은 크기로 고치고 mtime을 되돌린 파일도 재검증한다. 조건부 요청은 검증 후 304다.
  JSON은 파일 식별자를 키로 16개 캐시한다. 런타임 자료를 불변으로 다루는 계약은 유지한다.
- 지표 로딩 실패 시 낡은 지형 대신 자료 없는 참고 구와 오류를 표시한다. `selectStop`의
  성공 여부를 직접 반환해 맨틀 로더가 DOM 클래스·aria 속성으로 결과를 추측하지 않게 했다.
- 같은 맨틀 원본 시점에 해당하는 중간 나이 입력은 시간 선택을 스냅하고 메시를 재요청하지 않는다.
  연결 팝업의 오류에서도 다른 연대나 재시도를 선택할 수 있고, 대기 중 낡은 설명 모형도 숨긴다.
- 독립 맨틀은 WebGL 컨텍스트가 복구되면 선택 연대를 다시 불러온다.
- 대화상자 CSS·JS는 홈 뷰어와 맨틀 페이지에서만 읽는다. import map은 첫 모듈보다 앞에
  두고, 독립 단면의 자체 import map도 유지해 #38을 되돌리지 않는다.
- 해안선·판 경계는 구면에서만 원본 대권 선분을 0.1° 이하로 세분화한다. 확대 때 현의 처짐으로
  선 중간이 사라지는 현상을 줄이며, 큰 고정 높이 여유를 다시 넣지 않는다. 평면 투영은 그대로다.
  이는 표시 기하이며 관측이나 원자료의 정확도 향상이 아니다.
- `npm test`는 모든 `*.test.mjs`를 실행한다. 처리 검사 명령은 `docs/geodynamics.md`에 모았다.
- 배포 스모크는 Compose가 해석한 실제 published port를 사용한다. `.env`를 셸로 실행하지 않는다.
  패커는 단면 파일의 경로·해시부터 검증하고 JSON을 읽는다. gzip은 패커·두 서버에서 모두 선택 사항이다.
- 단면 묶음의 라이선스·변경 표기를 보완하고 ZIP 내부 경로에 `PurePosixPath`를 쓴다.

## 화면 확인과 계획 정정

수정 전·후 `test-results/p06-lines-{before,after}-{0,5,20}.png`를 캡처했다. 수정 전 바다 위의
긴 선분 중간이 사라졌던 구간이 세분화 후 이어진다. ×5·×20은 음영 강도이며 높이 과장이 아니다.

기존 응답의 `nosniff`는 Django 미들웨어가 이미 추가했다. iframe의 `src` 제거도 Chromium에서

## 남은 범위

PaleoDEM 카탈로그는 원본 아카이브를 고정하지만 파생 PNG의 기대 해시는 갖지 않는다.
단면 빌더가 기록하는 PNG 해시는 입력 추적용이며 별도 기대값과의 비교 검증은 아니다.
이를 검증하려면 PaleoDEM 산출물 manifest 도입이 먼저 필요하다. 이 항목과 선택 유지보수인
전체 JS 포맷 정리·넓은 모듈 분리·브랜치 정리는 후속으로 남겼다.
버전 올림·운영 배포·원본 및 전체 런타임 자료 재생성은 수행하지 않았다.

구현 PR [#40](https://github.com/jikhanjung/EarthThruTime3D/pull/40)은 사용자 배포 요청 후 병합했다.
릴리스·배포는 [075](20260916_jikhanjung_075_release_0130.md)에 이어 기록한다.
