# jikhanjung 047 — 도구 막대의 표시 자료 선택, devlog 작성자별 번호

날짜: 2026-09-14

## 한 것

### 표시 자료 선택

고도 격자 시리즈(`?masks=paleodem2018`)는 "변환 방식과 자료"를 펼쳐야 보이는 비교 링크로만
들어갈 수 있었다. 기온, 해수면, 빙하, 지형 음영 버튼은 이 시리즈에서만 나오므로, 오늘 합친
기능 대부분이 사실상 숨어 있었다.

- 지구본 아래 도구 막대 맨 앞, 투영 선택 앞에 "표시 자료" 드롭다운을 두었다. 자료를 바꾸면
  그 옆 버튼(기온, 빙하 등)이 달라지므로 같은 막대에 둔다. 순서는 PaleoAtlas(2016) 기본,
  PaleoDEM 고도 격자(2018), 2002년판 웹 지도다.
- 고도 격자는 전부 만들어진 경우에만 목록에 나온다. 비교 링크와 같은 조건이다
  (`complete`). 격자가 빠진 체크아웃에서 고르면 다른 자료로 돌아가 버리기 때문이다.
- 자료마다 시점 목록을 서버가 만드므로, 자료를 바꾸면 새 페이지를 연다. 간격 선택과 같게
  지금 나이를 `age`로 넘겨 가장 가까운 시점에 내리고, `interval`/`steps`도 그대로 둔다.
- 기존 비교 링크는 그대로 둔다.
- 막대 안에 들어가도록 선택지는 짧은 이름("PaleoAtlas 2016", "고도 격자", "웹 지도 2002",
  영어 "Elevation", "Web maps 2002")으로 보이고, 전체 제목은 툴팁으로 둔다. 전체 제목을 쓰니
  데스크톱 고도 격자 화면에서 "시점 초기화"가 막대 밖으로 밀렸다. 도구 막대 드롭다운은 폭을
  10rem으로 제한했다. 고도 격자 화면은 버튼이 셋 더 있어 1280 px 폭에서도 끝 버튼이 조금
  잘리고, 막대를 가로로 밀어 보게 된다. 원래 이 막대는 좁을 때 가로로 밀어 보는 구조다.

### devlog 작성자별 번호

작업자가 둘이 되어 파일명을 `YYYYMMDD_{author}_{nnn}_{title}.md`로 바꿨다.

- 공용 번호에 작성자만 붙이면, 같은 날 두 사람이 같은 다음 번호를 잡는 문제가 그대로 남는다.
  그래서 번호도 작성자별로 나눴다. jikhanjung은 046부터, wwolf는 001부터다.
- 기존 001–045는 이름을 바꾸지 않았다. 파일 링크 44곳과 본문 속 "(012)" 같은 번호 참조
  36곳이 깨지고 git 이력 추적이 번거로워지기 때문이다.
- AGENTS.md의 "main에서 다음 공용 번호를 잡는다"는 규칙을 작성자별 번호로 바꿨다. 같은 규칙을
  CLAUDE.md에도 적었다.
